# 스파이 대전쟁 (HAHA 2 Shoot) — 웹앱 게임 제작 패키지

두 장의 손그림 메모를 바탕으로 작성한 기획·개발 문서, 게임 에셋, 그리고 이를 구현한 로컬 웹 게임(알파 버전)입니다. **2인 대결**과 AI를 상대하는 **싱글 플레이**를 지원합니다. 게임 제목은 손그림 기획서의 타이틀 화면대로 **스파이 대전쟁**입니다(처음 쓰던 가칭 HAHA 2 Shoot은 저장소·밸런스 복사 글 등에 남아 있습니다).

**타이틀 화면**: 메인 메뉴 맨 위에 기획서 그림처럼 테두리 안에 '스파이 대전쟁' 제목, 왼쪽에 온이름·피자럭스, 오른쪽에 요원 1·요원 2가 서로 총을 겨누고 가운데에서 총알이 부딪쳐 번쩍입니다(캐릭터 그림을 HTML·CSS로 배치, `index.html`의 `.title-art`).

## 실행

빌드·의존성 없는 정적 웹앱(ES 모듈 + Canvas 2D)입니다. ES 모듈은 `file://`에서 열리지 않으므로 정적 서버로 엽니다.

```sh
npm start        # python3 -m http.server 8000 → http://localhost:8000
npm test         # node --test, 이동·조준·발사·무기 선택·수류탄·총기 피해·체력·엄폐물·드론·전투기·통계·밸런스·AI 로직 검증
```

코드 구조는 [웹앱 기술 설계](docs/04-technical-design.md)의 `src/` 계약을 따릅니다(`.ts` 대신 `.js`). 기획 대비 단순화한 점: 키 재배정 UI 없음, 준비 화면은 슬롯별 준비 표시 대신 시작 버튼 하나, 터치와 키보드는 모든 슬롯에서 항상 함께 받습니다. 기획 문서의 4인 모드는 2인 전용으로 바꾸면서 뺐습니다. 실제 터치 기기에서의 다중 접점·성능 검수(docs/06 "실제 기기에서 확인")는 아직 수행하지 않았습니다.

## 핵심 게임

지구방위팀과 ISB팀이 **건물 옥상**에서 대결합니다. 화면은 **1인칭 3D**로, 내 캐릭터의 눈으로 보며 싸웁니다. 각 팀은 처음엔 위·아래 끝줄에 서지만 **경기장 어디로든(가운데를 지나 상대 진영까지) 앞뒤·좌우로 자유롭게** 움직이고, 고개를 돌려 **어느 쪽이든(360도)** 쏠 수 있습니다. 엄폐물은 걸어서는 뚫고 지나갈 수 없습니다.

**거대한 경기장·빠른 이동·꾹 누르는 점프·위아래 시선(업데이트)**
- **이동 속도**: 플레이어·요원(AI) 모두 초당 300 → **800**(4배로 올렸다가 1.5배 줄임, 아크 트루퍼 420 → 1120, 공중전 건쉽도 같은 배율·데스스타 2배). 회피 돌진도 같은 비율(초당 4000)입니다(`config.js`의 `SPEED_SCALE` = 4/1.5).
- **점프**: 살짝 누르면 약 80, **누르고 있는 동안(최대 0.45초) 위로 더 밀어 올려** 꾹 누르면 약 600까지 뛰고(예전 120·900의 1/1.5, `JUMP_SCALE`: 뛰는 속도·중력·밀어 올리는 힘을 같은 비율로 줄여 체공 시간은 그대로), 엄폐물(84)·높이 92 고지대는 조금 꾹 눌러야 넘습니다. AI도 탄을 뛰어넘어 피할 때는 잠깐 꾹 누릅니다. 모은 만큼 공중에서 최대 1.6배 빨라져 **훨씬 멀리** 날아갑니다(`JUMP.holdTime`·`holdAccel`·`airBoost`). 키보드는 점프키를 누르고 있는 동안, 컨트롤러 Y·터치 점프 버튼도 누르고 있는 동안 모읍니다. AI도 높은 구조물에 막히면 꾹 눌러 뛰어넘습니다.
- **위아래 시선·조준**: 마우스 위아래(포인터 잠금), P1 `R`/`V`, P2 `PageUp`/`PageDown`, 컨트롤러 오른쪽 스틱 위아래, 터치 시선 스틱을 위아래로 크게 밀어 고개를 들고 숙입니다(최대 약 80°, `PITCH`). 쏜 탄도 그 각도로 날아갑니다(사람 플레이어의 예전 자동 위아래 조준은 없앴고, AI만 씁니다).
- **탄속 3배**: 모든 총기(라이트닝·건쉽·존슨 저격총 포함, 던지는 수류탄·전기충격기는 그대로)의 탄속이 원래 표의 3배입니다(`BULLET_SPEED_SCALE`). 화염방사기는 사거리가 그대로 짧도록 불꽃 수명을 1/3로 줄였습니다.
- **탄은 어떤 구조물도 뚫지 못함**: 고지대·건물·다리 상판·오르막길·컨테이너·바닥·(복도 홀의) 천장에 닿으면 막히고, 튕기는 에너지 볼트는 그 면에서 튕깁니다(`src/game/terrain.js`의 `structureHit`). 원래 경기장의 높이 92 고지대도 땅에서 쏜 탄을 막습니다. 엄폐물은 예전처럼 높이 뛰거나 높은 곳에서 쏘면 위로 넘어갑니다. 폭발은 높이가 크게 다르면(건물 위·아래) 닿지 않습니다.
- **다른 사람의 조준선은 보이지 않음**: 3D 화면 칸마다 그 화면 주인의 빨간 조준선만 보이고(위아래 각도 따라 구조물에 닿는 곳까지), AI·상대·동료의 조준선은 그리지 않습니다(2D 대체 화면도 조준선 없음). 존슨 요원의 빨간 저격 예고선은 보스 패턴이라 그대로 보입니다.
- **모든 스테이지 넓이 10배**(가로·세로 각 √10배, `src/game/maps.js`의 `MAP_AREA`): 2인 대결의 넓은 옥상·고공 요새와 스토리 1스테이지 옥상은 약 15800×12600(예전 5000×4000의 10배), 스토리 복도·하늘·도로·대교는 약 5000×3200(원래 1600×1000의 10배). 원래 배치(가운데)는 그대로 두고, 그 둘레를 **스테이지에 맞는 거대한 건축물**로 채웁니다(경기장 가운데 기준 점대칭, 늘 같은 배치):
  - 옥상: 불 켜진 **거대한 빌딩**(높이 520~900, 옆에 꼭대기까지 띄워 주는 점프 패드), **계단식 탑**(꾹 눌러 한 칸씩), 두 탑을 잇는 **높은 다리**(밑으로 지나다님), **오르막길**로 올라가는 높은 단, 컨테이너 무리.
  - 복도: 본부의 **거대한 홀**(천장 높이 2000, 뛰어도 천장을 뚫지 못함). 철판 구조물·계단식 구조물·공중 통로·오르막길·화물 상자, 엘리베이터 탑·계단실·포탑 기둥.
  - 하늘: 넓어진 하늘에 탄을 막는 **방공 기구**(떠 있는 엄폐물).
  - 도로: 여러 차선의 넓은 도로에서 함께 달리는 **거대한 트레일러·운반차**(위에 설 수 있음)와 고가 통로·경사로·점프 패드.
  - 대교: 넓어진 다리 위 **거대한 주탑**(높이 700~1000)·계단식 비계·고가 통로·오르막길·멈춘 버스. 배가 지나는 가운데 틈은 비워 둡니다.
  - **구름 위 하얀 섬**(2인 대결 경기장 칸의 세 번째, 연속 플레이에서도 고름): 맑은 낮 하늘·구름 바다 위에 떠 있는 하얀 타일 섬(약 15800×12600). 가운데 시작 자리 사이의 커다란 아치(두 기둥 + 높이 520 공중 다리, 밑으로 지나다님), 남북 끝 높이 780 하얀 탑과 점프 패드, 동서 계단식 탑, 둘레를 빽빽하게 채운 하얀 블록 탑·계단식 탑·공중 다리·오르막길·기둥 숲·점프 패드, 높은 탑 꼭대기끼리·땅으로 이어진 검은 케이블, 하얀 엄폐물(`maps.js`의 `CLOUD_CORE`·테마 `cloud`, 3D는 `world3d.js`의 `buildCloud`·`models.js`의 `makeWhiteBlock`).
  - **연속 플레이 스테이지 고르기**: 스토리 모드 시작 칸에서 '♾️ 연속 플레이 모드'를 고르면 아래에 스테이지 칸이 나와 옥상·고공 요새, 넓은 옥상, 구름 위 하얀 섬, 본부 대형 홀(복도 포탑), 도로(탱크·트레일러), 대교(배·주탑) 중에서 고릅니다(마지막 선택은 저장, `story.js`의 `ENDLESS_MAPS`). 요원은 어느 스테이지든 헬리콥터로 옵니다. 하늘(공중전)은 비행기 스테이지라 빠집니다.
- **강습 건쉽(상점 탈것, 100코인)**: 총기 개조 → 상점 → '탈것'에서 100코인에 사면 캐릭터 선택(2인 대결·싱글 플레이)에 나옵니다(사기 전에는 숨김, `mods.js`의 `VEHICLE_SHOP`, `config.js`의 `assault-gunship`).
  - 체력 3000(다른 캐릭터의 3~6배), 몸 판정 반지름 80, 비행 속도 초당 960. 무기는 고정: 주무기 **미사일 5연발**(작은 미사일 5발, **발당 7**: 5발이 부채꼴로 흩어져 나가 공중에서 저마다 빠르게 원을 **3바퀴** 그리며(도는 방향은 번갈아) 나선 연기를 남긴 뒤 가장 가까운 적에게 세게 유도됨, `config.js`의 `pattern`, `update.js`의 `flyPattern`), 보조무기 **유도미사일**(한 발 50, 쿨타임 4초: 쏘면 공중으로 솟으며 빠르게 원을 그리다가 잠시 공중에 멈춰 '조준!' 한 뒤 가장 가까운 적에게 곧장 빠르게 날아감). 수류탄은 없습니다(예전 양쪽 캐논은 없앴습니다).
  - **비행**: 스테이지 상공을 날며 점프키(Space·오른쪽 Ctrl·컨트롤러 Y·'올라가기' 버튼)를 누르고 있으면 오르고, 회피키(왼쪽 Shift·M·컨트롤러 LT·'내려가기' 버튼)를 누르고 있으면 내려갑니다. 손을 떼면 그 높이에서 바라보는 쪽을 보며 떠 있습니다(호버링). 바닥·건물 위 40보다 낮게, 2600(복도 홀은 천장 아래)보다 높게는 못 갑니다. 건물 옆면에는 막히고, 격추되면 연기를 뿜으며 떨어집니다(`update.js`의 `updateFlight`, `FLIGHT`).
  - **시선**: 위·아래·양옆 모두 볼 수 있고(쏘는 방향도 같음), 화면은 **3인칭**(건쉽 뒤 위에서)입니다(`world3d.js`의 `thirdPerson`). AI도 떠 있는 높이를 겨눠 쏩니다.
  - **미사일 5연발은 늘 계속 쏩니다**: 발사키를 누르지 않아도, 유도미사일을 들고 있어도 1초마다 5발씩 쏘고(`autoFire`), 발사키는 유도미사일에 씁니다. 양옆 포드에서 **조준점**(조준 방향으로 처음 닿는 적·구조물·바닥, 없으면 4000 앞)까지 빨간 **조준선 두 줄**이 이어지고, **크로스헤어**는 화면 가운데가 아니라 그 조준점이 화면에 비치는 자리에 나옵니다(`update.js`의 `autoFire`, `world3d.js`의 `placeGunshipLines`).
  - 모습은 이 게임용으로 새로 디자인한 어두운 장갑 수직이착륙 건쉽입니다: 아래로 좁아지는 육각 조종석과 푸른 유리, 넓게 펼친 각진 장갑 지붕 두 겹과 뒤 계단 꼬리판, 각진 팔에 매단 팔각 엔진 포드(앞 덕트 팬이 돎)와 포드마다 아래 쌍 캐논(`models.js`의 `makeAssaultGunship`, 선택 그림 `assets/characters/assault-gunship.svg`). 날개 아래 양쪽에 미사일 발사기 4개씩(붉은 탄두), 날개 끝 양쪽에 개틀링건 1개씩(미사일을 쏠 때 총열이 빠르게 돎), 바닥 랜딩기어(앞 하나·뒤 둘), 뒤쪽 엔진부(붉게 빛나는 배기구 둘), 지붕 위 RPG 2개를 달았습니다. 공중전(하늘) 스테이지에서는 **라이트닝 대신 건쉽 그대로** 자기 무기로 싸웁니다(그 스테이지에서는 다른 비행기와 같은 높이로 고정).
- **새 주무기**(모든 일반 캐릭터, 처음부터): **3점사 소총**(당길 때마다 3발을 빠르게, 한 발 12, 30발), **개틀링**(총열 여섯 개가 돌며 아주 빠르게 연사, 한 발 5, 200발·장전 3.5초), **AK-47**(나무 개머리판, 한 발 11·0.13초마다, 30발), **투척용 쌍수단검**(양손 단검 2개를 빠르게 연달아 던짐, 탄속이 빠르고 한 개 26, 2개 다 던지면 새 단검을 손가락에 걸고 뱅글뱅글 세 바퀴 돌리며 0.8초 만에 다시 채움, 날아가는 단검도 빙글빙글 돎). 스토리 요원의 무작위 무기에는 넣지 않았습니다(스토리 설정에서 요원마다 고를 수는 있음).
- **장전 소리**: 탄창을 갈아 끼울 때 크게 **'철컥!'**(빈 탄창 빼기, 툭 떨어짐) … **'철컥! 철컥!'**(새 탄창 꽂기·노리쇠 놓기) 소리가 납니다. 묵직한 금속 맞물림·저음이 들어간 합성음을 미리 녹음해 두고 크게(1.8배) 재생합니다. 투척용 쌍수단검·화염방사기는 탄창이 없어 소리를 내지 않습니다(`audio/synth.js`의 `bigClack`·`reloadOut`·`reloadIn`).
- **보조무기 최대 3개**: 준비 화면의 보조무기 줄에서 누를 때마다 넣고 빼며 최대 3개를 고릅니다(고른 순서가 보조무기 1·2·3 칸, 버튼 오른쪽 위 번호). 경기 중 무기 전환(E·휠·오른쪽 Shift·컨트롤러 RB/X)은 주무기 → 보조무기 1 → 2 → 3 → 주무기 순서이고, P1 `1`~`4`·P2 숫자패드 `1`~`4`로 칸을 바로 고릅니다. 조작 패널에도 보조무기 칸마다 버튼이 있습니다. AI도 가진 보조무기 중에서 골라 쓰고(상대가 가까우면 카타나, 탄이 날아오면 방패), 스토리 요원은 예전처럼 하나만 씁니다(`config.js`의 `MAX_SECONDARIES`·`normalizeSecondaries`, `update.js`의 `slotsOf`·`weaponOfSlot`).
- **새 보조무기**(`config.js`의 `WEAPONS`, 수치는 밸런스 메뉴에서 조정):
  - **샷건 유도**: 부채꼴 5발이 가장 가까운 적 쪽으로 초당 2.4라디안까지 휘어 날아갑니다.
  - **화염폭탄**(쿨타임 10초): 조준 후 떼면 포물선으로 던져(고개를 들수록 멀리) 떨어진 곳에서 터지고(반경 150, 15), 바닥에 반경 220 불길이 5초 동안 남아 그 안의 적에게 초당 30 피해를 계속 줍니다(높이 뛰어 있으면 닿지 않음).
  - **카타나**(쿨타임 15초): 조준 후 떼면 앞을 가로로 크게 베어 150도 부채꼴·거리 280 안의 적 모두에게 120(단검은 몸에 닿아야 함). 구조물 뒤는 베지 못합니다.
  - **폭동 진압 방패**(쿨타임 10초): 누르면 몸 앞에 투명한 방패를 세워 6초 동안 앞쪽 140도에서 오는 공격(탄·폭발·칼·돌진)의 피해를 합쳐 500까지 막습니다(넘으면 깨짐). 다른 사람에게는 3D 방패가, 내 화면에는 남은 막을 피해·시간이 보입니다.
  - **섬광탄 권총**(쿨타임 8초): 조준 후 떼면 섬광탄이 곡선으로 날아가 떨어진 곳에서 번쩍 터지고, 반경 420 안에서 섬광이 보이는(구조물에 가리지 않은) 적은 가까울수록 오래(최대 3초) 눈이 멉니다. 사람은 화면이 하얗게 바래고, AI는 그동안 겨누지도 쏘지도 못합니다.
  - 손에 든 모습(1인칭·3인칭): 카타나(가로 베기 동작), 투명 방패, 초록 병 화염폭탄, 주황 섬광탄 권총(`guns.js`).
  - 점프 패드는 높이(`pad.h`)·세기(`pad.power`)를 따로 가져 건물마다 꼭대기까지 띄우고, 레이더는 거대한 맵에서 3600까지 보이며 멀리 있는 사람은 레이더 가장자리에 붙여 방향을 알려 줍니다.


**넓은 맵(2인 대결·자유 대전)**: 원래 옥상 경기장(1600×1000)을 가운데에 두고 사방으로 크게 넓힌 **거대한 옥상(5000×4000, 원래의 12.5배)**에서 싸웁니다(시작 자리는 원래대로 가운데 근처). 가운데 둘레에는 **계단식 탑** 2개(북·남, 높이 64 → 128 → 190을 한 칸씩 뛰어 올라감, 꼭대기에서 맵 전체가 내려다보임), 빨강·파랑·초록·노랑 **화물 컨테이너** 8개(높이 92, 뛰어올라 위로 다닐 수 있음), 네 귀퉁이 **전망대**(계단식), 길목마다 **엄폐물** 18개가 더 있고(모두 점대칭), 가운데에서 사방으로 노란 길 안내 점선이 나 있습니다. 가장자리는 빨간 경고등이 달린 난간이고, 그 둘레에 물탱크·환풍기·태양광 판·안테나, 더 멀리 밤 도시가 보입니다. 탄은 맵 끝(난간)까지 날아가고 RPG는 난간에서 터집니다. 레이더는 넓은 맵에서 더 멀리(2000) 보이고 고지대를 옅은 노란 네모로 보여 줍니다. AI는 상대 둘레 350~700 거리로 자리를 옮겨 다니며 넓은 맵에서도 따라오고, 엄폐물·컨테이너에 막히면 뛰어넘습니다. 건 카타 수련장은 원래 크기이고, 스토리 1스테이지 옥상은 아래 **고공 요새**입니다. 배치는 `src/game/config.js`의 `FIELD`·`WIDE_HIGHS`·`WIDE_COVERS`, 3D 바닥·장식은 `src/render/world3d.js`의 `buildField`입니다.

**고공 요새(2인 대결에서 고르는 경기장 · 스토리 1스테이지 옥상)**: 2인 대결 준비 화면 맨 위 **경기장** 칸에서 **넓은 옥상**(위)과 **고공 요새** 중 고릅니다(마지막 선택은 브라우저에 저장). 고공 요새는 넓은 맵과 같은 크기(5000×4000)에 원래 옥상 경기장을 가운데 두고, 북쪽 양옆에 **매우 높은 고지대 2개**(높이 340, 불 켜진 창문 줄이 있는 콘크리트 탑, 꼭대기 귀퉁이에 경고등·하늘로 뻗는 탐조등), 그 둘을 잇는 **높은 다리**(같은 높이, 빛나는 난간 띠·기둥), 서쪽 고지대로 남쪽에서 걸어 올라가는 **오르막길 1개**(노란 미끄럼 방지 줄), 밟으면 **매우 높이 튀어 오르는 점프 패드 3개**(약 530 높이, 공중에서 방향을 틀어 고지대·다리 위에 내려섬), 동쪽 고지대 남쪽 끝에서 남쪽으로 길게 뻗은 **고지대보다 약간 낮은(270) 긴 다리**(끝에서 뛰면 고지대로 올라감)가 있고, 엄폐물 12개가 흩어져 있습니다. 다리는 위에 설 수 있지만 **그 아래로는 밑으로 지나다닙니다**. 오르막길은 비탈을 따라서만 오르고 옆에서 높은 쪽으로는 막힙니다. 높이 차이가 큰 상대(고지대·다리 위 또는 그 아래)는 **고개를 들고 숙여(위아래 시선)** 겨눠 맞힙니다(AI는 조준 방향 14° 안의 상대 높이로 탄을 기울여 쏩니다). 수치는 `src/game/config.js`의 `FORTRESS_HIGHS`·`FORTRESS_PADS`·`FORTRESS_COVERS`·`PAD`·`VERTICAL_AIM`, 3D는 `src/render/world3d.js`의 `buildFortress`·`src/render/models.js`의 `makeFortress`·`makeBridgeDeck`·`makeRamp`·`makeJumpPad`입니다.

**점프·고지대**: **점프**(P1 `Space`, P2 오른쪽 `Ctrl`, 컨트롤러 Y, 조작 패널 '점프' 버튼)하면 약 120 높이까지 뛰어올랐다 내려옵니다(공중에서 다시 뛰지는 못함). 높이 떠 있으면 **엄폐물을 뛰어넘고**, 땅에서 쏜 탄보다 충분히 높으면 **탄이 밑으로 지나갑니다**. 경기장에는 노랑·검정 줄무늬 가장자리의 **고지대**(철판 단) 4개가 있습니다: 가운데 양옆(높이 92, 상대 진영으로 넘어가는 길목)과 진영마다 하나씩(높이 64, 점대칭). 걸어서는 옆면에 막히고 **뛰어올라야 올라서며**, 그 위에서는 눈높이가 높아져 멀리 보이고 **쏜 탄이 엄폐물 위로 넘어갑니다**(점프 중에 쏴도 마찬가지). 가장자리로 걸어 나가면 떨어집니다. 다른 사람이 뛰거나 고지대에 선 모습도 3D로 그 높이에 보입니다. 공중전·도로·대교 스테이지에는 고지대가 없습니다. 수치는 `src/game/config.js`의 `JUMP`·`HIGHS`·`COVER_HEIGHT`입니다. AI는 넓은 맵에서 길이 막히면 뛰어넘습니다.

**회피(빠른 돌진)**: **회피**(P1 왼쪽 `Shift`·마우스 휠 클릭, P2 `M`, 컨트롤러 LT·오른쪽 스틱 누르기, 조작 패널 '회피' 버튼)를 누르면 움직이던 쪽(이동 입력이 없으면 앞)으로 0.18초 동안 빠르게 돌진합니다(약 270 거리, 걷기의 5배 빠르기). **돌진하는 동안 받는 피해는 30% 줄고**, 사격·점프는 그대로 됩니다. **2번 연속**으로 돌진할 수 있고(돌진 중에 다시 누르면 바로 새 방향으로), 쓴 뒤 마지막 돌진이 끝나고 **0.5초 쿨타임**이 지나면 다시 2번으로 채워집니다. 남은 횟수는 왼쪽 아래 내 체력 칸의 '회피 ●●'와 조작 패널 버튼에 보이고, 돌진 중에는 화면에 속도선이 지나가며 시야가 살짝 넓어집니다(동작 줄이기면 생략). 공중전(비행기)에서는 쓸 수 없습니다. 수치는 `src/game/config.js`의 `EVADE`입니다.

**조준점·체력바**: 조준점은 검은 테두리를 두른 작은 형광 연두 십자와 가운데 점으로, 밤하늘·회색 바닥·붉은 조준선 위에서도 보입니다(쏠 수 없는 동안은 흰색, 맞히면 붉은 X). 왼쪽 아래 내 체력은 진한 판 위의 막대와 숫자(25% 아래면 판 테두리가 붉게)이고, 머리 위 체력바는 작게 그립니다. 화면이 작게 줄어들면 HUD를 조금 키웁니다(조준점 최대 1.6배, 체력 칸·팀 체력판 최대 1.3배).

발사키를 **누르고 있는 동안 자동으로 발사**됩니다. 플레이어는 **체력 500**(온이름은 1000)으로 시작하며, 화면 왼쪽 아래에 내 체력, 다른 사람 머리 위에 이름·체력바, 오른쪽 위 팀 패널에 모두의 체력이 표시됩니다.

**1인칭 3D 화면**(three.js, [`src/render/world3d.js`](src/render/world3d.js)·[`src/render/models.js`](src/render/models.js)): 게임 규칙·판정은 예전처럼 위에서 본 경기장(1600×1000) 좌표로 계산하고, 그것을 3D로 그립니다(경기장 1px = 3D 1단위, 눈높이 128). 캐릭터는 그림을 늘 나를 보는 판(빌보드)으로, 헬리콥터·건쉽·전투기·라이트닝·데스스타·자동차·트럭·탱크·배·포탑·낙하산은 코드로 만든 3D 모델로 그립니다. 조준점(맞히면 X 표시), 맞은 방향 표시, 왼쪽 위 **레이더**(위에서 본 작은 지도, 보는 쪽이 위), 피해 숫자, 라이트닝 조종석은 그 위 2D 캔버스(HUD)에 그립니다.

**손에 든 총(3D)**([`src/render/guns.js`](src/render/guns.js)): 1인칭 화면 오른쪽 아래에 **장착한 무기 모양 그대로 실제 총처럼 생긴 3D 총**을 검은 양복 소매·흰 소맷부리·맨손으로 쥐고 있습니다. 실제 총의 옆모습을 다각형으로 그려 두께만큼 밀어 만들고, 금속은 주변 빛이 비치게 그립니다. 무기를 바꾸면 총을 내렸다 올리고, 걸을 때 흔들리며, 쏠 때마다 뒤로 튑니다.

**총기 개조(개조 모드)**: 메인 메뉴의 **총기 개조**를 누르면 **작업실 책상**(3D: 나무 책상·작업 매트·공구 걸린 구멍판 벽·탁상 조명)이 나오고, 고른 총이 장착한 파츠를 단 채 책상 위에 놓여 있습니다(끌어서 돌려 보기). **랜덤 뽑기**(1회 1코인·10연속 10코인)를 누르면 책상 오른쪽 **뽑기 상자**의 뚜껑이 열리고 가장 좋은 등급 색의 빛이 솟으며 파츠가 떠오르고, 결과 카드가 나옵니다. **코인**은 처음 시작할 때 **기본 100코인**을 받고(`STARTER_COINS`, 예전부터 하던 저장에도 한 번만 주며, 예전에 기본 10코인을 받았으면 모자란 90코인만 더 줌), 스토리 모드에서 **스테이지를 깰 때마다 1개**씩 바로 들어오므로(대교까지 깨면 마지막 승리 때 1개), 중간에 그만두거나 져도 그때까지 받은 코인은 남습니다(경기 화면 위에 '코인 +1' 알림, 메인 메뉴 '총기 개조' 버튼과 작업실 위에 가진 코인 표시). 뽑은 파츠는 **배낭**에 저장되고(이 브라우저에 저장, `src/game/mods.js`), 배낭에서 눌러 보면 책상 왼쪽 받침 위에 그 파츠가 떠서 돌고, **장착**을 누르면 지금 고른 총에 붙고, 장착한 파츠는 배낭 카드의 **장착 해제**(또는 위 장착 칸의 '해제')로 떼어 기본 부품으로 돌아갑니다(총마다 따로, 같은 파츠를 여러 총에 붙여도 됨). **분해**는 두 번 눌러 배낭에서 지웁니다.

**상점(구매)**: 작업실 오른쪽 위 **랜덤 뽑기 · 상점 (구매)** 탭에서 상점을 고르면 맨 위에 **전설 무기 3가지(에너지 돌격소총·에너지 쌍권총·에너지 RPG, 각 50코인)**가 있습니다. 전설 무기는 스킨이 아니라 **새 주무기**라, 사면 무기 선택(2인 대결·싱글 플레이·AI 무기)의 주무기 목록에 나타납니다(영구, `src/game/mods.js`의 `LEGEND_SHOP`, 필터 '전설 무기'). 카드를 누르면 책상 위에 그 무기를 올려 미리 봅니다. 산 전설 무기는 작업실의 개조할 총 목록에도 ★로 나타나 **파츠를 붙여 커스텀**할 수 있습니다(에너지 돌격소총: 개머리판·총구·스코프·총 색깔, 에너지 쌍권총: 총구·스코프·총 색깔, 에너지 RPG: 스코프·총 색깔 — 총 색깔은 흰 외장판과 검은 몸통 색을 바꾸고 푸른 빛 띠·육각 문양은 그대로). 에너지 돌격소총에는 기본으로 검은 망원 조준경이 달려 있습니다(개조 스코프를 달면 그것으로 바뀜). 그 아래에는 **레어 30가지·엘리트 30가지, 모두 60가지 총기 스킨**을 코인으로 골라 살 수 있습니다(**레어 3코인 · 엘리트 8코인**). 총기 스킨 하나는 그 총(돌격소총·기관단총·저격총·샷건·권총·쌍권총·RPG·아킴보 석궁, 8가지에 골고루)에 붙는 **모든 칸의 파츠를 한 벌로 맞춘 완성형 외형**이고(예: '황금 용 샷건', '코발트 돌격소총'), 뽑기 파츠처럼 **모양만** 바꿉니다. 카드를 누르면 책상 위 총에 미리 붙여 보여 주고, **구매**하면 파츠 한 벌이 배낭에 들어가 그 총에 바로 장착됩니다. 산 총기는 **영구 보관**되어(이 브라우저에 저장, 다음에 접속해도 남음) 배낭에서 **분해할 수 없고**('상점' 표시), 다른 파츠로 바꿨다가도 상점 카드의 **보유 · 장착**으로 한 번에 다시 장착합니다. 같은 총기는 한 번만 살 수 있습니다. 목록은 `src/game/mods.js`의 `SHOP`(고정 seed라 디자인이 늘 같음), 필터는 전체·레어·엘리트·지금 고른 총만.

| 파츠 칸 | 붙일 수 있는 총 | 종류(등급이 높을수록 다양) |
| --- | --- | --- |
| 개머리판 | 돌격소총·기관단총·저격총·샷건 | 고정식·접이식·스켈레톤(구멍 뚫림)·정밀(뺨받침 조절)·윙(엘리트) |

| 스코프 | 모든 총 | 접이식 가늠자·도트·홀로그램·프리즘·장거리·열상(빛나는 화면) |

등급은 **일반(60%) · 희귀(25%) · 레어(11%) · 엘리트(4%)** 이고, 높을수록 잔장식(홈·링·나사)이 늘고 색 장식이 붙으며, 엘리트는 금빛·크롬 재질과 **빛나는 줄**이 붙어 가장 멋있습니다. 파츠 하나하나의 모양(종류·길이·굵기·구멍 수·색·무늬)과 이름은 뽑을 때마다 새로 정해지는 숫자(seed)로 그때그때 만들어 내므로 같은 종류라도 디자인이 계속 새로 나옵니다(`src/render/parts.js`). 파츠는 **모양만** 바꾸고 피해·장탄 수 같은 수치는 바꾸지 않으며, 경기 중 **1인칭 손에 든 총에도 장착한 파츠가 그대로 보입니다**(장전할 때 바꾼 탄창이 빠졌다 들어감). 화면 코드는 [`src/ui/workshop.js`](src/ui/workshop.js)입니다.

**총구 불꽃·연기**: 쏠 때마다 총구에서 **불꽃이 번쩍이고**(잠깐 주변과 손·총을 밝히는 빛) **옅은 연기**가 피어올라 퍼지며 사라집니다(샷건·RPG·저격총은 크게, RPG는 뒤로도 후폭풍). 다른 사람이 쏠 때도 그 사람 총구에서 불꽃·연기가 납니다. **날아가는 탄은 진짜 총알 모양**(구리 탄두 + 놋쇠 몸통, 뒤로 옅은 팀 색 빛줄기, 샷건은 납 산탄, 석궁은 화살, 레이저는 빛 덩어리)입니다. '동작 줄이기'를 켜면 연기는 나오지 않습니다.

**피격·조준 표시**: 맞으면 **화면 테두리가 붉게 빛나고**(맞은 쪽 방향에 붉은 호), 체력이 25% 아래로 떨어지면 테두리가 두근두근 계속 붉게 빛납니다. 조준점은 **빨간 십자**(장전·쿨타임 중엔 회색, 맞히면 흰 X)이고, 총구에서 조준 방향으로 **빨간 조준선(레이저)**이 엄폐물·사람에 닿는 곳까지 뻗어 끝에 빨간 점이 찍힙니다. 다른 사람(적·동료)의 조준선도 옅게 보여 어디를 겨누는지 알 수 있습니다(공중전·컷씬에서는 숨김).

**적이 든 무기**: 3D 화면에서는 캐릭터마다 **무기를 지운 그림**(`assets/characters/<캐릭터>-bare.png`: 무기 영역을 지우고 몸에 가려졌던 곳을 메움, 요원 2·피자럭스는 무기 없는 요원 1 몸에 머리를 옮겨 붙임)을 쓰고, 그림 속 **손 자리**(`assets/manifest.json`의 `hands`)에 **지금 든 무기의 3D 모델**의 손잡이를 쥐여 줍니다. 다른 사람(적·동료·2인 대결 상대)은(돌격소총·권총·쌍권총·저격총·RPG·샷건·석궁 등, 사람 플레이어는 개조 파츠까지)을 조준 방향으로 겨누고, 총알이 떨어지면 **장전 동작**(탄창 빼고 끼우기, RPG 로켓 끼우기, 쌍권총 돌리기)을 그대로 보여 줍니다. 쓰러지면 총은 보이지 않습니다.

**체력바·대사**: 처치 컷씬(킬캠)에서도 등장인물 이름표·체력바와 말풍선(무전·도발)이 3D 화면 위에 보이고, 컷씬·처치 컷씬 동안 왼쪽 위에 내 체력바가 계속 나옵니다. 대사는 아래 검은 띠에 자막으로 나옵니다. **두 사람이 하면(2인 대결·스토리 2인 협동) 화면이 좌우로 나뉘고**(P1 왼쪽, P2 오른쪽), 컷씬·처치 컷씬·대교 가는 길은 장면에 맞춘 3D 카메라로, **건 카타는 예전처럼 옆에서 본 2D 화면**으로 나옵니다(그동안 3D 화면은 숨김). 내 바로 옆에 붙어 선 사람은 화면을 가리지 않게 흐리게 보입니다. WebGL을 쓸 수 없는 기기에서는 예전처럼 위에서 내려다본 2D 화면으로 그립니다. three.js(MIT 라이선스, r169)는 빌드 없이 쓰도록 [`src/vendor/three.module.min.js`](src/vendor/three.module.min.js)에 넣어 두었습니다(라이선스: [`src/vendor/three.LICENSE`](src/vendor/three.LICENSE)). 체력이 0이 되면 쓰러지고, **상대 팀을 모두 쓰러뜨리면 승리**합니다(같은 순간 양 팀 전멸은 무승부). 아군 공격은 불가능합니다.

한 경기는 P1·P2 두 자리로 겨룹니다(싱글 플레이에서는 P2가 AI, 아래 참고). **2인 대결**에서는 경기 전 준비 화면에서 P1(지구방위팀)·P2(ISB팀)가 각각 **캐릭터 5명 중 하나와 주무기·보조무기를 고릅니다.** 고른 무기는 경기 중에 바꿀 수 없고, 경기 중에는 둘 중 들 무기만 바꿉니다.

화면 아래 조작 패널은 플레이어마다 화면 절반을 쓰며, **이동키(바깥쪽)와 시선·발사키(안쪽)를 패널 양 끝에 두어** 두 손이 겹치지 않게 했습니다. 이동키는 **위로 밀면 앞, 아래로 밀면 뒤, 옆으로 밀면 옆걸음**, 시선·발사키는 **옆으로 민 만큼 고개를 돌리고 밀고 있는 동안 발사**합니다(위로 밀면 돌지 않고 정면으로 발사, RPG·저격총은 밀었다가 놓으면 발사). 두 스틱 사이에는 버튼 3개가 있습니다.

**키보드·마우스**: P1은 `W`/`S` 앞뒤, `A`/`D` 옆걸음, **마우스**(게임 화면을 클릭하면 포인터가 잠기고, 좌우로 움직여 고개를 돌림. `Esc`로 풀면 일시정지) 또는 `Z`/`C`로 고개 돌리기, `F`·왼쪽 클릭 발사, `E`·휠 무기 전환, `Q`·오른쪽 클릭 수류탄. P2는 `↑`/`↓` 앞뒤, `←`/`→` 고개 돌리기, `,`/`.` 옆걸음, `Enter` 발사, 오른쪽 `Shift` 무기 전환, `/` 수류탄. 혼자 하면 P1은 P2 키(방향키 등)로도 움직입니다. 코드는 [`src/input/keyboard.js`](src/input/keyboard.js)·[`src/input/view.js`](src/input/view.js)에 있습니다.

| 버튼 | 동작 | 키보드 P1 / P2 |
| --- | --- | --- |
| 주무기 · 보조무기 | 누른 무기로 바로 전환(든 무기는 팀 색으로 표시). 전환 직후 0.4초 동안은 쏠 수 없음 | `E` / 오른쪽 `Shift` (두 무기 사이 전환) |
| 아이템(수류탄) | 든 무기와 상관없이 **바라보는 쪽으로 수류탄을 바로 던짐**. 쿨타임 동안 버튼에 남은 초 표시 | `Q` / `/` |

**게임 컨트롤러**(Xbox·PlayStation·Switch Pro 등 브라우저 Gamepad API 표준 배치)로도 조작할 수 있습니다. 연결된 순서대로 첫 번째 컨트롤러가 P1, 두 번째가 P2이며(싱글 플레이에서는 P1만), 터치·키보드와 함께 받습니다. 브라우저는 컨트롤러 버튼을 한 번 눌러야 컨트롤러를 인식합니다. 코드는 [`src/input/gamepad.js`](src/input/gamepad.js)에 있습니다.

밸런스 조정 메뉴에서 즉사기의 **피해**(9999면 즉사, 줄이면 그만큼만), **유도 각도**(조준 방향에서 최대 몇 도까지 휘는지, 180이면 어디를 겨눠도 명중·작게 하면 비슷하게 겨눠야 맞음), **사용 가능 시각**(전투 시작 후 몇 초), **쿨타임**(쏜 뒤 다시 쓸 때까지)을 바꿀 수 있습니다. 경기가 끝나면 마지막 한 방이 보이도록 결과 화면은 약 1초 뒤에 뜹니다.

RPG는 가장 가까운 적 쪽으로 휘어 날아가며(초당 최대 약 46°, 약하게), 빗나가도 벽(경기장 끝)·수명 끝에서 반드시 터져 주변에 폭발 피해를 줍니다.

경기장(1600×1000)에는 **엄폐물 3개**가 있습니다. 가운데 1개와 각 팀 진영 앞에 1개씩(점대칭 배치)이며, 양 팀 총알을 막고 RPG는 엄폐물에 닿으면 그 자리에서 폭발합니다. 엄폐물은 **내구도 200**이며 양 팀 총알(한 발 피해만큼), RPG 직격(2배, 80), RPG 폭발 범위(10)에 깎입니다. 전투기 미사일은 엄폐물 위로 넘어가므로 막히지도 깎지도 않습니다. 깎일수록 금이 가고 위에 내구도 바가 뜨며, 0이 되면 부서져 그 경기 동안 다시 생기지 않습니다. 주무기로 **저격총**을 고른 플레이어가 있으면, 그 팀 진영(팀 엄폐물 반대쪽)에 경기 내내 **강철 엄폐물**이 하나씩 생깁니다. 강철 엄폐물은 부서지지 않고 양 팀 총알·레이저를 모두 막습니다.

가끔 **전투기**가 무작위로 나타나 경기장 가운데 하늘 위를 가로로 지나갑니다. 전투기는 높이 날기 때문에 **총알·RPG·레이저는 전투기 밑으로 그냥 지나갑니다**(막지 않음). 화면 안에 있는 동안 **1초마다 양 팀 진영으로 미사일**을 한 발씩, 그 진영에서 **가장 가까운 사람이 있던 자리**를 노려 쏩니다. 미사일은 직격 20에 주변 폭발 피해 8(반경 120)이고, 유도 없이 똑바로 날아가며, 엄폐물을 넘어가 플레이어에게 직접 날아갑니다. 빗나가면 노린 자리에서 터지므로 쏘는 걸 보면 옆으로 비키세요. 전투기가 지나가는 동안 위치에 따라 좌우로 움직이는 엔진 소리가 나고, 총을 쏠 때마다 총기별 총성이 납니다. 기본 수치는 [`src/game/config.js`](src/game/config.js)의 `CHARACTERS`·`WEAPONS`·`JET`·`COVER`·`RULES`에 있습니다. 두 번째 손글씨 메모(무기표·체력·자동 발사·옥상·전투기)를 반영한 업그레이드이며, 이전 버전의 "10점 선취" 규칙은 체력제로 바뀌었습니다.

### 싱글 플레이 (vs AI)

메인 메뉴의 **싱글 플레이**에서 혼자 AI와 대결합니다. 플레이어는 P1(지구방위팀) 자리에서 캐릭터 5명 중 누구든 고르고, AI는 P2(ISB팀) 자리에서 **요원 1·요원 2 중 경기마다 무작위**로 정해집니다. 설정 화면에서 AI에 대해 다음을 정할 수 있으며, 설정은 브라우저에 저장됩니다.

| 설정 | 내용 |
| --- | --- |
| 난이도 | 쉬움·보통·어려움. 탄을 알아채는 속도, 피하려는 확률, 이동 속도, 조준 예측, 연사 습관, 수류탄 빈도가 달라짐 |
| AI 주무기·보조무기 | 주무기 5종(+숨겨진 아킴보 석궁), 보조무기(기관단총·단검·샷건) 중 플레이어가 정함 (수류탄은 공통) |
| AI 히트박스 | 몸 판정 반지름 (기본 30, 클수록 잘 맞음) |
| AI 체력 | 기본 500 |
| AI 탄속 | 무기 기본 탄속 대비 % (기본 100%) |
| 주무기·보조무기·수류탄 피해 | AI만 적용. 비워 두거나 기본값이면 무기 기본 피해(RPG는 폭발 피해도 같은 비율로) |

AI는 **언제나 플레이어를 향해 조준**하고(보통·어려움은 플레이어가 움직이는 방향 앞을 예측), 날아오는 플레이어의 탄·RPG·수류탄과 전투기 미사일을 **8방향으로 움직여 피하고**, 평소에는 자기 진영 안에서 앞뒤·좌우로 자리를 옮깁니다. 엄폐물에 가로막히면 트인 자리로 옮기고, 가끔 기관단총으로 바꿔 쓰며 쿨타임이 끝나면 수류탄을 던집니다. AI 자리의 키보드 키(방향키·Enter 등)는 쓰이지 않습니다. **명중률·점프**: AI(요원·동료)는 난이도와 상관없이 상대가 움직이는 쪽 앞을 예측해 겨누고(넓은 맵 범위까지), 쏜 총알이 상대가 갈 자리 쪽으로 살짝 휘어 날아가는 **조준 보정**(쉬움·보통·어려움 초당 0.9·1.4·2 라디안, 폭발·화염·던지는 무기는 제외)이 있어 좌우로 계속 달리는 상대도 잘 맞힙니다(시험에서 명중률 약 65·79·78%, 예전 3·7·50%). 또 곧 닿을 탄을 난이도별 확률(20·45·70%)로 **점프해 피하고**, 평소에도 가끔 뜁니다. 코드는 [`src/game/ai.js`](src/game/ai.js)에 있습니다.

### 스토리 모드 (싱글 플레이)

싱글 플레이 화면 맨 위에서 **자유 대전**(위의 AI 1:1) 대신 **스토리 모드**를 고르면, 플레이어(P1) 혼자 ISB팀 요원들을 웨이브마다 상대합니다.

**2인 협동**: 스토리 모드를 고르면 나오는 인원 칸에서 **1인 · 2인 협동**을 고릅니다. 2인 협동이면 P2도 **지구방위팀**으로 P1과 같은 진영에서 함께 싸웁니다(화면은 좌우로 나뉨)(P2 캐릭터·무기는 그 아래 P2 칸에서 고르고, 기본은 피자럭스 돌격소총). P2는 2인 대결처럼 **오른쪽 조작 패널**·방향키(`←`/`→`·`↑`/`↓`·`Enter`·오른쪽 `Shift`·`/`)·두 번째 컨트롤러로 조작합니다. 요원 수·체력은 1인과 같고, 요원과 복도 포탑은 **가까운 주인공**을 노립니다. 한 명이 쓰러져도 다른 한 명이 서 있으면 계속하고, **둘 다 쓰러지면 패배**입니다. 쓰러진 동료는 **스테이지를 깰 때(옥상 → 복도) 체력 가득으로 다시 일어납니다**. 킬캠·엔딩 컷씬의 주인공은 그 요원·보스를 쓰러뜨린 쪽입니다. 저장하기는 두 사람의 체력·선택을 함께 저장하고(쓰러진 쪽은 체력 0, 이어 하면 쓰러진 채로), 이어하기는 저장할 때의 인원으로 이어 합니다. 스테이지는 **1스테이지 옥상**, **2스테이지 복도**, **3스테이지 하늘**, **4스테이지 도로**, **5스테이지 대교** 다섯 개입니다. **웨이브를 깰 때마다 서 있는 주인공·AI 동료의 체력이 100% 회복**되고(연속 플레이 포함), 쓰러진 동료는 **스테이지를 깰 때** 체력 가득으로 일어납니다. 웨이브를 깨면 쓰러진 요원은 치워지고 다음 웨이브가 옵니다.

**일반 요원의 무기**: 스토리 모드의 일반 요원(보스·하늘의 건쉽 제외)은 주무기 외에 **보조무기로 기관단총·샷건 중 하나**를 들고 와 가끔 바꿔 쓰고, **수류탄도 던집니다**(AI 난이도에 따라 빈도가 다름, `src/game/story.js`의 `AGENT_SECONDARIES`).

**AI 동료**: 스토리 모드 인원 칸 아래에서 **AI 동료 없음·1명·2명·3명**을 고르면 지구방위팀 AI가 함께 싸웁니다(1인·2인 협동 모두). 동료마다 **캐릭터와 주무기를 직접 고릅니다**(동료 수를 고르면 그 아래에 동료 칸이 나옴, 캐릭터를 고르면 주무기는 그 캐릭터의 그림 속 무기로 바뀌고 다시 바꿀 수 있음, R-10은 레이저 캐논 고정). 동료는 AI(난이도 보통)이고 **주무기만 씁니다**(보조무기·수류탄 없음). 고른 동료는 브라우저에 저장됩니다. 그 대신 **동료 수만큼 일반 웨이브마다 보통 난이도의 돌격소총 요원이 더 나옵니다**(체력 등은 그 웨이브 설정과 같음, 스미스 요원·R-10 보스전에는 추가 없음). 동료가 쓰러져도 계속하고, 쓰러진 동료는 스테이지를 깰 때 일어납니다. **사람 주인공이 모두 쓰러지면 동료가 남아 있어도 패배**입니다. 동료가 요원을 쓰러뜨려도 건 카타는 사람 주인공이 하고, 저장하면 동료 수도 함께 저장됩니다.

**연속 플레이 모드**: 싱글 플레이 → 스토리 모드의 시작 스테이지 칸에서 **♾️ 연속 플레이 모드**를 고르면, **1스테이지 옥상(고공 요새)만** 나오고 헬리콥터가 **요원을 3명씩 끝없이** 데려옵니다(웨이브 무한, 보스·다음 스테이지 없음, 요원 체력·무기는 스토리 설정의 옥상 2웨이브 칸, AI 동료가 있으면 그 수만큼 더). **웨이브를 깰 때마다 랭크 1레벨**(1승리, 30레벨이면 승급과 20코인), **웨이브마다 1코인**을 받고, 받는 즉시 저장되므로 **중간에 그만두거나 쓰러져도 보상은 남습니다**. 화면 왼쪽에 몇 번째 웨이브인지·오른 레벨·받은 코인·다음 코인까지 남은 웨이브가 보이고, 주인공이 모두 쓰러지면 끝나 결과 화면에 돌파한 웨이브 수가 나옵니다. **웨이브마다 요원이 점점 강해집니다**: 깬 웨이브 수만큼 체력 +12%씩(계속), 피해 +6%씩(최대 3배), 이동 속도·탄속 +2%씩(최대 1.5배) 오르고, 3웨이브부터는 적어도 보통, 6웨이브부터는 어려움 난이도 AI가 됩니다(웨이브 시작 안내에 '강화 +N'). 연속 플레이는 저장하기·스테이지 건너뛰기가 없습니다. 수치는 `src/game/story.js`의 `ENDLESS`·`endlessBoost`.

R-10을 쓰러뜨리면 3스테이지 하늘(공중전), 하늘의 보스 데스스타를 쓰러뜨리면 4스테이지 도로, 도로의 보스 윌슨 요원을 쓰러뜨리면 대교 가는 길(운전) 뒤 5스테이지 대교로 넘어가고, 대교의 보스 존슨 요원을 쓰러뜨리면 승리(스토리 클리어), 플레이어가 쓰러지면 패배입니다. 일반 요원은 주무기만 쓰고, 헬리콥터·엘리베이터·천장에서 들어오는 동안에는 맞지도 움직이지도 않습니다. 연출 중에는 평소의 전투기가 나오지 않습니다.

**스테이지 건너뛰기**: 스토리 모드 중 일시정지 화면의 **"N스테이지 ○○로 건너뛰기"** 버튼을 누르면 지금 스테이지를 건너뛰고 다음 스테이지 처음부터(체력 가득) 시작합니다. 같은 캐릭터·무기·2인 협동·AI 동료로 가고, 마지막 스테이지(대교)에서는 버튼이 없습니다(도로에서 건너뛰면 대교 가는 길 없이 대교 처음부터). 싱글 플레이 화면의 스토리 칸에서 **시작 스테이지**(1 옥상·2 복도·3 하늘·4 도로·5 대교부터)를 골라 처음부터 건너뛰고 시작할 수도 있습니다.

**저장하기 · 이어하기**: 스토리 모드 중 일시정지 화면의 **저장하기**를 누르면 지금 싸우는 웨이브(웨이브 사이라면 다음에 올 웨이브)와 체력, 고른 캐릭터·무기를 브라우저에 저장합니다. 메인 메뉴로 나가거나 창을 닫았다가 다시 들어와도 메인 메뉴(또는 싱글 플레이 화면의 스토리 칸)의 **스토리 이어하기**로 그 웨이브의 요원이 오는 장면부터 저장한 체력으로 이어 합니다(쓰러뜨리던 요원은 처음부터). 스미스 요원 엔딩 컷씬 중에 저장하면 복도 1웨이브·체력 가득으로 저장됩니다(윌슨 요원 엔딩·대교 가는 길 중이면 대교 1웨이브·체력 가득). 이어 하거나 저장한 판에서 **재대결·다시 시작**을 누르면 그 저장 위치부터 다시 하고, 스토리를 끝까지 깨면 저장은 지워집니다. 싱글 플레이 화면의 **저장 지우기**로 지울 수도 있습니다.

**건 카타 모드(모든 요원·스미스 요원·R-10)**: 스토리 모드에서 **요원을 쓰러뜨릴 때마다**(스미스 요원과 R-10 포함) **건 카타 모드**에 들어갑니다. 화면이 **옆에서 본 시점**(옥상은 밤의 옥상 끝과 도시 불빛, 복도는 본부 복도)으로 바뀌어 주인공(왼쪽)과 쓰러뜨린 적(오른쪽)이 마주 보고 서고, 조작 패널은 모두 사라지고 **가운데에 1·2·3·4 버튼**만 남습니다. 적이 아래 네 가지 공격을 무작위로 하는데, **공격하기 1.5초 전부터 눌러야 할 버튼이 1.5초 동안 빛납니다**(화면 가운데에도 번호와 줄어드는 시간 고리). 빛나는 동안 그 버튼을 누르면 대응(반격) 성공, **1.5초 안에 못 누르거나 다른 버튼을 누르면 체력 100이 깎입니다**. **일반 요원은 3번, 보스(스미스 요원·R-10)는 10번 대응하면** 건 카타가 끝나고 원래 장면이 이어집니다: 일반 요원은 처치 컷씬(킬캠: 마지막 한마디·웨이브 마무리 장면), 스미스 요원은 아래 엔딩 컷씬, R-10은 RPG 엔딩 컷씬. 2인 협동이면 그 적을 쓰러뜨린 주인공이 합니다. 체력이 0이 되면 패배입니다(2인 협동이면 살아 있는 동료가 이어받음). 건 카타 중에는 저장할 수 없고, 일시정지하면 그 자리로 돌아옵니다. 코드는 [`src/game/gunkata.js`](src/game/gunkata.js)(진행)·[`src/input/kata.js`](src/input/kata.js)(버튼)이고, 그림은 `src/render/canvas.js`의 건 카타 부분입니다.

**스미스 요원 엔딩 컷씬**: 건 카타를 끝내면 약 8초 컷씬이 나옵니다(위아래 검은 띠와 자막). 스미스 요원이 다시 일어나 주인공에게 달려들고, 주인공이 권총을 6발 쏘지만 스미스 요원은 모두 옆으로 피합니다(MISS). 코앞까지 온 스미스 요원을 주인공이 **발로 차서(퍽!)** 옥상 끝 난간 너머 **건물 밖으로 떨어뜨립니다**. 컷씬이 끝나면 계단 컷씬이 이어집니다.

**계단 컷씬(옥상 → 복도)**: 약 8초. 주인공이 "계단으로 내려가자!" 하고(2인 협동이면 둘이 함께, 쓰러져 있던 동료도 일어나) 옥상 계단실의 '계단 ▼' 문으로 걸어가 계단을 내려갑니다. 화면이 어두워진 동안 경기장이 복도로 바뀌고(체력 100% 회복, 엄폐물·포탑·엘리베이터 준비), 주인공이 복도 왼쪽 벽 아래쪽 '계단' 문에서 나와 자기 자리로 걸어간 뒤 카운트다운부터 2스테이지가 시작됩니다. 컷씬 중 저장하면 복도 1웨이브로 저장됩니다.

**R-10 엔딩 컷씬**: R-10을 쓰러뜨리면 결과 화면 전에 약 9초 컷씬이 나옵니다. R-10이 다시 떠올라 **레이저 광선을 마구 쏘지만 주인공이 좌우로 피하고**(모두 빗나감), 주인공이 "후, RPG가 남아있었지." → R-10 "그게 무슨-" → 주인공이 **RPG를 쏴 R-10을 폭발**시킵니다. 이어서 아래 라이트닝 컷씬 뒤 3스테이지 하늘이 시작됩니다. 컷씬 동안은 조작할 수 없고, 일시정지하면 컷씬 그 자리로 돌아옵니다.

**라이트닝 컷씬(복도 → 하늘)**: 약 10초. 화면이 어두워졌다가 **옥상으로 올라온 주인공**이 무전으로 "본부! 여기는 옥상. **내 전용기 라이트닝을 보내 줘!**" → 본부 "라이트닝 출격! 행운을 빈다." → 라이트닝(쌍동 프로펠러 전투기)이 날아와 주인공 위에 멈추고, 주인공이 올라타 날아오르면 화면이 하얘지며 3스테이지 하늘로 바뀝니다(체력 100% 회복). 이 컷씬 중에 저장하면 하늘 1웨이브로 저장됩니다.

**3스테이지 · 하늘(공중전)**: **비 내리는 밤, 도시 상공**입니다. 진짜 날아가는 것처럼 아래의 도시(불 켜진 건물 지붕·가로등 길·달리는 차 불빛)와 가까운 비구름이 계속 뒤(화면 아래)로 흘러가고, 빗줄기가 비스듬히 떨어지며 가끔 번개가 번쩍입니다(동작 줄이기를 켜면 멈춤). 지구방위팀 전원(2인 협동 P2·AI 동료 포함)이 **라이트닝**을 타고 자기 진영 하늘에서 싸웁니다(1인칭 화면은 **조종실 안**: 앞 유리와 좌우 옆창으로만 바깥과 적이 보이고, 창틀 기둥·지붕·계기판(원형 계기·레이더/자세계 화면·경고등·조종간)이 둘러쌈. 체력이 25% 아래면 맨 왼쪽 경고등이 빨갛게 깜빡임). 엄폐물·포탑은 없습니다. 무기가 공중전용으로 바뀝니다.

**낙하산 컷씬(하늘 → 도로)**: 약 8초. 주인공(2인 협동 P2·AI 동료도)이 "놈들을 놓칠 순 없지. 뛰어내린다!" 하고 **라이트닝에서 뛰어내리고**(라이트닝은 위로 날아감), **낙하산**(빨강·흰 줄무늬)이 펴지며 비 내리는 도시로 작아지며 내려갑니다. 화면이 어두워지는 동안 도로로 바뀌고(체력 100% 회복), 밝아지면 낙하산을 타고 위에서 내려와 **도로를 달리는 각자의 차 지붕에 내려앉습니다**. 낙하산은 접히며 뒤로 날아갑니다.

**4스테이지 · 도로**: **비 내리는 밤, 도시의 넓은 도로**를 위에서 내려다봅니다. 모두 오른쪽으로 달리고 있어 차선 점선·가로등 불빛·젖은 노면의 반사·갓길 난간이 계속 뒤(왼쪽)로 흘러가고, 비가 내리며 노면에 물방울이 튀고 가끔 번개가 칩니다. **모두 달리는 자동차 위에서 싸웁니다**: 주인공(과 동료)은 파란 스포츠카, ISB 요원은 경광등을 단 검은 세단 지붕에 서고, 옆으로 움직이면 차도 함께 움직입니다. 무기는 라이트닝을 타기 전(땅에서) 쓰던 주무기·보조무기·수류탄으로 돌아옵니다. 엄폐물은 짐칸에 실린 짐(평판 트럭이 함께 달림)이고, 스테이지를 시작할 때 새로 생깁니다.

**ISB 요원도 차를 타고** 경고("ISB 추격 차량 접근!") 뒤 **뒤(왼쪽 화면 밖)에서 차례로 달려와** 자기 진영에 붙습니다(오는 동안은 맞지 않음). 요원을 쓰러뜨리면 다른 스테이지처럼 건 카타(달리는 트레일러 지붕 위)와 처치 컷씬이 나옵니다. 1웨이브 마지막 요원은 무전으로 "추격대! 전부 따라붙어!", 3웨이브를 깨면 화면이 붉어지며 윌슨 요원(초상에 RPG 두 자루)이 무전으로 "추격대가 당했나… 내 RPG 두 자루로 끝내 주지." → 보스전.

**보스 · 윌슨 요원**: RPG 두 자루를 든 ISB 요원(체력 800, 그림은 요원 2 + 코드로 덧그린 두 번째 RPG)으로, 자기 차를 타고 뒤에서 따라붙습니다. 무기는 전용 **쌍 RPG**: **쏘는 방식은 쌍권총과 같고**(0.5초마다 2점사, 한 발 10) 탄이 **작은 로켓 모양**이라 맞거나 벽에서 **터지며**(폭발 범위 8, 반경 90) **유도는 없고**, 날아간 길에 **회색 연기**가 남았다가 퍼지며 사라집니다. 보조무기·수류탄은 쓰지 않습니다. 쓰러뜨리면 10번 대응하는 건 카타("로켓이 떨어졌군… 맨손으로 상대해 주마!") 뒤 **윌슨 요원 엔딩 컷씬**(약 7.6초): 비틀거리던 윌슨 요원의 차가 "끼이이익—!!" 미끄러지며 빙글 돌아 뒤로 처지고 갓길에 부딪혀 연달아 폭발 → 주인공 "본부, 윌슨 요원 처리!" → 본부 무전 "아직이다! ISB 잔당이 눈 내리는 대교로 모이고 있다!" → 아래 대교 가는 길. 쌍 RPG 수치(피해·연사 간격·탄속·점사 수·점사 간격·폭발 피해/반경)는 밸런스 조정의 **도로(스토리 4스테이지) · 탱크 · 윌슨 요원** 칸(`src/game/config.js`의 `WEAPONS.dualrpg`), 윌슨 요원의 체력·히트박스·난이도 등은 스토리 설정의 도로 보스전 칸에서 바꿉니다. **대교 가는 길(도로 → 대교)**: 윌슨 요원 엔딩 컷씬 끝에 본부가 "ISB 잔당이 눈 내리는 대교로 모이고 있다!"고 무전하면, 스테이지를 깬 것이라 **체력이 100% 회복**되고(쓰러진 동료도 일어남) **자동차를 직접 몰아** 눈 내리는 길을 달립니다(약 20초, 위에서 내려다보는 시점, 손그림 코스처럼 가운데 노란 점선·양쪽 갓길에 가로등과 눈더미). 차는 위로 달리고 길이 아래로 흘러가며, **좌우 이동(이동 스틱·`A`/`D`·방향키·컨트롤러)으로 핸들을 꺾어** 길 위의 **구멍**(검은 동그라미)과 **눈더미**를 피합니다. **구멍에 빠지면 "덜컹!" 체력 20**이 깎이고(쓰러지지는 않음, 체력 1까지) 잠깐(0.8초) 다시 빠지지 않으며, **이렇게 깎인 체력으로 대교에서 싸웁니다**. 눈더미에 부딪히면 잠깐 느려집니다. 장애물은 앞뒤로 떨어뜨려 놓아 늘 빠져나갈 길이 있습니다. AI 동료는 스스로 피합니다. 위쪽 막대에 대교까지 남은 거리가 보이고, 대교 입구(탑과 줄)를 지나면 화면이 어두워지며 5스테이지 대교로 바뀝니다. 수치(달리는 시간·속도·핸들 속도·구멍 피해·구멍/눈더미 수·무적 시간)는 밸런스 조정의 **대교(스토리 5스테이지)** 칸(`src/game/config.js`의 `DRIVE`)에서 바꿉니다.

**5스테이지 · 대교**(손그림 기획서): **눈 내리는 밤의 대교**를 위에서 내려다봅니다. 눈 덮인 다리 상판이 화면을 세로로 가로지르고(가운데 노란 점선, 양쪽 난간에 가로등과 눈더미, 바깥은 강), 눈이 내립니다. 주인공(과 동료)은 다리 위에 세운 자기 차 앞에서 싸우고, 엄폐물은 팀 진영 두 개입니다(가운데는 다리가 벌어지는 자리라 없음). 무기는 그대로입니다.

**배**: 대교에서는 전투기 대신 **다리 가운데가 벌어지고**(노랑·검정 줄무늬 상판 끝과 빨간 경고등, 1.5초 동안 열림) 그 틈의 강으로 **ISB 배**가 가로로 지나갑니다. 화면 안에 있는 동안 **1.2초마다 위(ISB)·아래(지구방위팀) 양쪽으로 대포**를 한 발씩 쏘고, 대포알은 **명중하면 5, 폭발 범위(반경 120)에 닿으면 2** 피해입니다. 전투기 미사일처럼 양 팀 모두 맞고, 엄폐물 위로 넘어가며, 빗나가면 노린 자리(그 진영에서 가장 가까운 사람이 있던 곳)에서 터집니다. 배가 지나가면 다리가 다시 닫힙니다. 결과 화면에는 '배'로 나옵니다. 수치는 밸런스 조정의 **대교(스토리 5스테이지)** 칸(`src/game/config.js`의 `SHIP`)에서 바꿉니다.

**보스 · 존슨 요원**: 저격총을 든 ISB 요원(체력 800, 보통 난이도, 그림은 요원 1 + 코드로 덧그린 저격총). 낙하산으로 내려앉으면 경기가 잠깐 멈추고 카메라가 존슨 요원을 확대하며 **"내가 처리하지…" → "…멍청이들."** 하고 빨간 조준선 세 줄과 함께 저격총을 쏘는 장면이 나옵니다. 싸우는 동안 **1.5초마다 저격총을 3발**씩 부채꼴로 한꺼번에 쏘는데, 쏘기 **0.8초 전부터 그 길이 빨간 선으로 표시**되고(그동안 존슨 요원은 멈춰 서서 겨눔) 선을 따라 날아옵니다(한 발 30, 엄폐물에 막힘). **체력을 절반 넘게 깎으면** "존슨 요원 분노!"와 함께 **5발**씩 쏩니다. 보조무기·수류탄은 쓰지 않습니다. 쓰러뜨리면 10번 대응하는 건 카타("이 거리라면… 저격총은 필요 없지.") 뒤 **존슨 요원 엔딩 컷씬**(약 7.5초): 비틀거리던 존슨 요원이 얼어붙은 다리에서 "미끄덩—!!" 빙글 돌며 가까운 난간 쪽으로 미끄러져 강으로 "풍덩!!" → 주인공 "본부, 존슨 요원 처리. 이번엔 정말 임무 완료!" → 결과 화면(스토리 클리어). 저격총 수치(한 발 피해·쏘는 간격·탄속·발 수·절반 아래 발 수·발 사이 각도·조준선이 보이는 시간)는 밸런스 조정의 **대교(스토리 5스테이지)** 칸(`WEAPONS.jsniper`), 존슨 요원의 체력·히트박스·난이도 등은 스토리 설정의 대교 보스전 칸에서 바꿉니다.

**탱크**: 도로에서는 전투기 대신 **ISB 탱크**가 가운데 차선을 따라 지나갑니다. 화면 안에 있는 동안 **1.4초마다 위(ISB)·아래(지구방위팀) 양쪽으로 포탄**을 한 발씩 쏘고(포신 두 개), 포탄은 **맞으면 5, 폭발 범위(반경 130)에 닿으면 2** 피해입니다. 전투기 미사일처럼 양 팀 모두 맞고, 엄폐물 위로 넘어가며, 빗나가면 노린 자리(그 진영에서 가장 가까운 사람이 있던 곳)에서 터집니다. 탄환은 탱크를 맞히지 못합니다. 결과 화면에는 '탱크'로 나옵니다. 수치는 밸런스 조정의 **도로(스토리 4스테이지) · 탱크 · 윌슨 요원** 칸(달리는 속도·첫 등장·재등장 간격·포탄 간격·피해·속도·폭발 피해/반경, `src/game/config.js`의 `TANK`)에서 바꿉니다.

**공중전 밸런스**: 밸런스 조정 메뉴의 **공중전(스토리 3스테이지 하늘)** 칸에서 라이트닝 기관포(피해·연사 간격·탄속·나란히 쏘는 발 수·간격), 과냉각(지속 시간·연사 간격 배율·켜져 있을 때 한 발 피해·쿨타임), 미사일(아이템)(피해·쿨타임·탄속·폭발 피해/반경), 건쉽 기관포·데스스타 산탄포(피해·연사·탄속·점사/산탄 수·부채꼴), 데스스타 미사일(갈래 수·부채꼴 각도·피해·쿨타임·탄속·폭발), 공중전 공통(배경 비행 속도·건쉽이 날아 들어오는 시간·데스스타 첫 미사일 시각)을 바꿉니다. 건쉽·데스스타의 체력·히트박스·난이도는 스토리 설정의 웨이브 칸에서 정합니다.

라이트닝·건쉽·데스스타·자동차·트럭·탱크·낙하산·대교·배·구멍·눈더미 그림은 모두 코드로 직접 그린 것입니다(`src/render/canvas.js`의 drawLightning·drawCarrier·drawDeathstar·drawCar·drawTruck·drawTank·drawChute·drawBridgeBackground·drawShip·drawDrive). 받은 참고 그림은 저장소에 넣지 않았습니다.

스토리 모드를 고르면 오른쪽에 스테이지별로 **웨이브별 요원 밸런스 칸**이 나옵니다. 웨이브마다 **난이도(쉬움·보통·어려움), 체력, 피해(%), 탄속(%), 이동 속도(%), 히트박스 반지름**을, 스미스 요원은 **보조무기**도 정합니다. **일반 요원(보스가 아닌 모든 웨이브, 하늘의 건쉽과 AI 동료 때문에 더 나오는 요원 포함)은 기본 난이도가 모두 보통**이고, 예전 기본값(쉬움·기획대로)으로 저장돼 있던 칸도 보통으로 바뀝니다. 직접 고른 다른 난이도는 그대로 둡니다. **요원마다 주무기**도 정할 수 있습니다(스미스 요원 포함, R-10은 레이저 캐논 고정): **무작위**(돌격소총·권총·쌍권총 중) 또는 돌격소총·권총·쌍권총·RPG·저격총·아킴보 석궁 중 하나이며, 칸 이름 옆에 기본 무기가 나옵니다. 위 표의 무기는 기본값입니다. 기본값과 다른 칸은 노랗게 표시되고, 값은 브라우저에 저장됩니다(**스토리 설정 기본값으로**로 되돌림). 맨 위의 **건 카타 모드** 칸에서 건 카타를 **끄면** 요원을 쓰러뜨려도 건 카타 없이 바로 처치 컷씬(보스는 바로 엔딩 컷씬)으로 넘어갑니다. **지금 설정을 내 기본값으로 저장**을 누르면 지금 설정(건 카타 켜기/끄기·웨이브별 값)이 그 브라우저의 '내 기본값'이 되어, 노란 표시와 **스토리 설정 기본값으로** 버튼이 그 값을 기준으로 합니다. **원래 기본값으로**는 '내 기본값'을 지우고 처음 값으로 되돌립니다. 결과 화면에는 플레이어와 이번 판에 나온 요원 전원의 통계가 나옵니다. 코드는 [`src/game/story.js`](src/game/story.js)(웨이브·연출), [`src/ui/story.js`](src/ui/story.js)(밸런스 칸)에 있습니다.

### 건 카타 수련장

건 카타의 **버튼을 누르는 시간제한**(버튼이 빛나는 시간, 기본 1.5초), **다음 공격까지 쉬는 시간**(최소·최대, 기본 0.55초로 같음, 다르게 하면 그 사이에서 무작위), **못 막았을 때 깎이는 체력**(기본 100)은 밸런스 조정의 **건 카타** 칸(`src/game/config.js`의 `KATA`)에서 바꿉니다. 스토리 모드와 수련장 모두에 적용됩니다.

메인 메뉴의 **건 카타 수련장**을 누르면 지구방위팀 훈련장에서 **훈련용 전투 로봇**과 **끝없이 건 카타만** 합니다(주인공은 마지막으로 고른 P1 캐릭터, 캐릭터를 바꾸려면 일시정지 → 캐릭터 선택). 조작은 스토리 모드의 건 카타와 같고(빛나는 1·2·3·4 버튼을 1.5초 안에), **체력은 무한**이라 틀리거나 늦어도 깎이지 않으며 연속 성공만 끊깁니다. 화면 위에 **연속 성공·대응 성공·실수·최고 연속**이 나오고, 연속 성공이 쌓일수록 공격 사이 쉬는 시간이 짧아집니다(최대 절반까지). 그만두려면 왼쪽 아래 일시정지 버튼(또는 `Esc`) → 메인 메뉴. 로봇 그림은 `assets/characters/training-bot.svg`(직접 쓴 SVG), 코드는 [`src/game/gunkata.js`](src/game/gunkata.js)의 `createTrainingMatch`입니다.

### 밸런스 조정 (알파)

메인 메뉴의 **밸런스 조정**에서 캐릭터별 체력·히트 박스 반지름·이동 속도, 무기별 피해·발사 간격(쿨타임)·탄속·점사·폭발 피해/반경·유도·배터리·과열, 수류탄, 엄폐물 내구도, 전투기 등장·미사일, 무기 전환 대기·탄환 수명을 바꿀 수 있습니다. 바꾼 값은 그 브라우저에 저장되어 다음 경기부터 적용되고, **모두 기본값으로**로 되돌립니다. **지금 수치를 내 기본값으로 저장**을 누르면 지금 수치가 그 브라우저의 '내 기본값'이 되어, 노란 표시·'기본 ○○' 안내·**모두 기본값으로**가 그 값을 기준으로 합니다. **원래 기본값으로**는 '내 기본값'을 지우고 모든 수치를 처음(`src/game/config.js`) 값으로 되돌립니다.

**현재 수치 보기**는 전체 수치를 한 화면에 모아 보여 줍니다. 기본값과 다른 칸은 노랗게, 괄호 안에 기본값을 표시하므로 그대로 캡처해 전달하면 됩니다. **텍스트로 복사**하면 같은 내용과 변경값 JSON이 복사됩니다. 전달받은 값을 새 기본값으로 삼으려면 `src/game/config.js`의 해당 수치를 고칩니다. 조정 가능한 항목 목록은 [`src/game/balance.js`](src/game/balance.js)에 있습니다.

### 계정 · 랭크

**계정**: 게임을 시작하면 먼저 **계정 1·2·3·4** 중 하나를 고릅니다(마지막에 고른 계정이 노랗게 표시, 메인 메뉴의 **계정 바꾸기**로 언제든 다시 고름). 계정마다 **랭크·코인·총기 개조(배낭·장착·산 전설 무기·스킨)·스토리 저장**이 따로 저장되어, 한 계정에서 플레이해도 다른 계정에는 영향이 없습니다(새 계정은 기본 100코인). 예전에 하던 저장은 계정 1로 이어집니다. 설정·밸런스·싱글 플레이 설정은 모든 계정이 함께 씁니다. 코드는 `src/game/rank.js`·`src/storage/settings.js`(`useAccount`·`loadRank`)·`src/game/mods.js`(`useAccount`).

**랭크**: 등급은 **초보 등급 → 일반 등급 → 중수 등급 → 고수 등급 → 전사 등급 → 전문가 등급 → 역전의 전사 등급** 7가지이고 등급마다 1~30레벨입니다. **2인 대결에서 승리**하거나(무승부 제외, 어느 쪽이 이겨도 지금 계정에) **스토리 모드를 스테이지 건너뛰기 없이 끝까지 깨면**(1스테이지부터 시작, 시작 스테이지 고르기·건너뛰기를 쓰지 않은 판. 저장했다 이어 해도 됨) **1레벨**씩 오릅니다. **30레벨이 되면 20코인**을 받고 바로 **다음 등급 1레벨로 승급**합니다(역전의 전사 등급은 30레벨이 끝, 그때도 20코인). 메인 메뉴 위에 계정·등급·레벨·승급까지의 막대, 결과 화면과 경기 화면에 레벨 업·승급 알림이 나옵니다.

**승리 포즈(2인 대결)**: 2인 대결이 끝나면 이긴 사람을 비추는 카메라로 바뀌어, 이긴 캐릭터가 **총을 하늘로 치켜들고 깡충깡충 뛰며** 'WINNER!'와 함께 팀 색·금빛 불꽃이 터지는 **승리 포즈**를 약 3.6초 보여 준 뒤 결과 화면이 뜹니다. 결과 화면 맨 위에도 이긴 캐릭터가 뛰는 'WINNER' 카드가 나옵니다(동작 줄이기면 움직임 생략).

### 결과 화면

경기가 끝나면 승자, 경기 시간과 함께 플레이어별 남은 체력·준 피해·받은 피해·초당 피해·명중률·엄폐물 피해·전투기에게 받은 피해·쓰러진 시각과 원인을 보여 주고, 준 피해 비교 막대와 **무기별 통계**(발사·명중·명중률·준 피해·발당 피해·엄폐물 피해) 표를 보여 줍니다. 명중은 상대에게 피해를 준 발 수(폭발 범위 포함)이고, 피해는 실제로 깎인 체력입니다.

### 무기별 캐릭터 그림

지금 캐릭터 그림은 캐릭터마다 한 장이며 기본 주무기가 그려져 있어(온이름 쌍권총, 요원 1 권총, 피자럭스 돌격소총, 요원 2 RPG, R-10 레이저 발사기), 무기를 바꿔도 모습은 그대로입니다. 온이름·요원 1 그림은 원래 그림을 편집해 만들었습니다(온이름 머리 + 요원 1의 쌍권총 든 몸, 넥타이는 파랑 / 요원 1은 들어 올린 권총을 지움). R-10은 직접 그린 SVG입니다. 무기별 그림을 넣으면 든 무기에 따라 모습이 바뀝니다.

1. `assets/characters/<캐릭터 id>@<무기 id>.png` 로 저장합니다. 예: `earth-arrow@sniper.png`
   - 캐릭터 id: `earth-arrow`, `earth-pizza`, `isb-agent-1`, `isb-agent-2`
   - 무기 id: `rifle`, `pistol`, `dual`, `rpg`, `sniper`, `smg`, `grenade`
   - 기존 그림처럼 정사각형·투명 배경·오른쪽을 보는 자세로 맞추면 됩니다.
2. `assets/manifest.json`의 `assets`에 항목을 추가합니다. `id`는 파일 이름과 같은 `<캐릭터 id>@<무기 id>`, `bodyAnchor`는 몸 중심 위치(0~1 비율)입니다. 기존 캐릭터 항목을 복사해 `id`·`path`만 바꾸면 됩니다.

그림이 없는 조합은 기본 그림을 그대로 씁니다. `assets` 폴더는 통째로 배포되므로 워크플로 수정은 필요 없습니다.

캐릭터 이미지는 정적 완성 포즈입니다. 움직이는 팔·총의 분리 파츠나 프레임 애니메이션 시트는 포함하지 않으며, MVP에서는 별도 조준선과 간단한 전체 스프라이트 변형으로 동작을 표현합니다.

## 배포 (GitHub Pages)

주소: https://umid-podo.github.io/hahaha-shoot-001/

`main`에 push하면 [`.github/workflows/deploy-pages.yml`](.github/workflows/deploy-pages.yml)이 게임 실행에 필요한 파일만 모아 배포한다. 문서와 테스트는 사이트에 올라가지 않는다. 게임이 새 파일이나 폴더를 쓰게 되면 워크플로의 `Collect game files` 단계에도 추가한다. 빠뜨리면 사이트에서 404가 난다.

### Claude Code Cloud에서 배포

"배포해줘"라는 요청을 받으면 아래 순서대로 진행한다. 클라우드 세션은 자기 작업 브랜치에만 push할 수 있으므로 PR로 `main`에 반영한다.

1. 테스트: `npm test`.
2. 변경 사항을 커밋하고 작업 브랜치를 push한다.
   ```sh
   git push -u origin HEAD
   ```
3. PR을 만들고 병합한다. 병합되면 `main` push로 배포가 자동으로 시작된다. 이미 열린 PR이 있으면 새로 만들지 않고 그 PR을 병합한다.
   ```sh
   gh pr create --repo umid-podo/hahaha-shoot-001 --base main --fill
   gh pr merge --repo umid-podo/hahaha-shoot-001 --merge
   ```
4. 병합이 막히면 작업 브랜치를 바로 배포한다. `github-pages` 환경은 `main`과 `claude/*` 브랜치의 배포만 허용한다.
   ```sh
   gh workflow run deploy-pages.yml --repo umid-podo/hahaha-shoot-001 --ref "$(git branch --show-current)"
   ```
   이 경우 `main`에는 아직 반영되지 않았으므로 사용자에게 PR 병합을 요청한다. 병합하지 않으면 다음 `main` 배포가 이 변경을 덮어쓴다.
5. 배포 실행이 끝날 때까지 기다린다. 실행 목록에 바로 보이지 않으면 몇 초 뒤 다시 조회한다.
   ```sh
   gh run list --repo umid-podo/hahaha-shoot-001 --workflow deploy-pages.yml --limit 1
   gh run watch <실행 ID> --repo umid-podo/hahaha-shoot-001 --exit-status
   ```
6. 사이트가 `200`을 돌려주는지 확인하고 주소를 사용자에게 알린다. 클라우드 네트워크에서 `github.io`에 접속할 수 없으면 5번의 성공 결과로 대신하고, 그렇게 보고한다.
   ```sh
   curl -s -o /dev/null -w '%{http_code}\n' https://umid-podo.github.io/hahaha-shoot-001/
   ```

### 로컬에서 배포

`main`에서 커밋하고 `git push`하면 된다. 확인은 위 5~6번과 같다.

### 처음 설정 (완료됨)

저장소 Settings → Pages의 Source는 **GitHub Actions**이고, Settings → Environments → `github-pages`의 배포 브랜치는 `main`, `claude/*`로 제한되어 있다. Pages 설정이 꺼졌다면 아래 명령으로 다시 켠다.

```sh
gh api -X POST repos/umid-podo/hahaha-shoot-001/pages -f build_type=workflow
```

배포 브랜치 제한이 사라졌다면 아래 명령으로 되살린다. 마지막 줄이 `claude/*,main`을 출력하면 된다.

```sh
echo '{"deployment_branch_policy":{"protected_branches":false,"custom_branch_policies":true}}' | gh api -X PUT repos/umid-podo/hahaha-shoot-001/environments/github-pages --input -
gh api -X POST repos/umid-podo/hahaha-shoot-001/environments/github-pages/deployment-branch-policies -f name=main -f type=branch
gh api -X POST repos/umid-podo/hahaha-shoot-001/environments/github-pages/deployment-branch-policies -f name='claude/*' -f type=branch
gh api repos/umid-podo/hahaha-shoot-001/environments/github-pages/deployment-branch-policies --jq '[.branch_policies[].name]|join(",")'
```
