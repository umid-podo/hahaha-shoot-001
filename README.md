# 스파이 대전쟁 (HAHA 2 Shoot) — 웹앱 게임 제작 패키지

두 장의 손그림 메모를 바탕으로 작성한 기획·개발 문서, 게임 에셋, 그리고 이를 구현한 로컬 웹 게임(알파 버전)입니다. **2인 대결**과 AI를 상대하는 **싱글 플레이**를 지원합니다. 게임 제목은 손그림 기획서의 타이틀 화면대로 **스파이 대전쟁**입니다(처음 쓰던 가칭 HAHA 2 Shoot은 저장소·밸런스 복사 글 등에 남아 있습니다).

**타이틀 화면**: 메인 메뉴 맨 위에 기획서 그림처럼 테두리 안에 '스파이 대전쟁' 제목, 왼쪽에 온이름·피자럭스, 오른쪽에 요원 1·요원 2가 서로 총을 겨누고 가운데에서 총알이 부딪쳐 번쩍입니다(캐릭터 그림을 HTML·CSS로 배치, `index.html`의 `.title-art`).

## 실행

빌드·의존성 없는 정적 웹앱(ES 모듈 + Canvas 2D)입니다. ES 모듈은 `file://`에서 열리지 않으므로 정적 서버로 엽니다.

```sh
npm start        # python3 -m http.server 8000 → http://localhost:8000
npm test         # node --test, 이동·조준·발사·무기 선택·수류탄·총기 피해·체력·엄폐물·드론·전투기·통계·밸런스·AI 로직 검증
```

코드 구조는 [웹앱 기술 설계](docs/04-technical-design.md)의 `src/` 계약을 따릅니다(`.ts` 대신 `.js`). 기획 대비 단순화한 점: 키 재배정 UI 없음, 준비 화면은 슬롯별 준비 표시 대신 시작 버튼 하나, 터치와 키보드는 모든 슬롯에서 항상 함께 받습니다. 기획 문서의 4인 모드는 2인 전용으로 바꾸면서 뺐습니다. 실제 터치 기기에서의 다중 접점·성능 검수(docs/06 "실제 기기에서 확인")는 아직 수행하지 않았습니다.

## 핵심 게임

지구방위팀과 ISB팀이 **건물 옥상**의 상·하단 레일에서 좌우(X축)로만 이동하며 대결합니다. 조준 스틱을 드래그해 경기장 안쪽 180도를 조준하면 **누르고 있는 동안 자동으로 발사**됩니다. 모든 플레이어는 **체력 500**으로 시작하며, 캐릭터 아래와 오른쪽 팀 패널에 체력바가 표시됩니다. 체력이 0이 되면 쓰러지고, **상대 팀을 모두 쓰러뜨리면 승리**합니다(같은 순간 양 팀 전멸은 무승부). 아군 공격은 불가능합니다.

한 경기는 P1·P2 두 자리로 겨룹니다(싱글 플레이에서는 P2가 AI, 아래 참고). **2인 대결**에서는 경기 전 준비 화면에서 P1(지구방위팀)·P2(ISB팀)가 각각 **캐릭터 5명 중 하나와 주무기·보조무기를 고릅니다.** 고른 무기는 경기 중에 바꿀 수 없고, 경기 중에는 둘 중 들 무기만 바꿉니다.

화면 아래 조작 패널은 플레이어마다 화면 절반을 쓰며, **이동키(바깥쪽)와 발사키(안쪽)를 패널 양 끝에 두어** 두 손이 겹치지 않게 했습니다. 두 스틱 사이에는 버튼 3개가 있습니다.

| 버튼 | 동작 | 키보드 P1 / P2 |
| --- | --- | --- |
| 주무기 · 보조무기 | 누른 무기로 바로 전환(든 무기는 팀 색으로 표시). 전환 직후 0.4초 동안은 쏠 수 없음 | `E` / 오른쪽 `Shift` (두 무기 사이 전환) |
| 아이템(수류탄) | 든 무기와 상관없이 **지금 조준 방향으로 수류탄을 바로 던짐**. 쿨타임 동안 버튼에 남은 초 표시 | `Q` / `/` |

**게임 컨트롤러**(Xbox·PlayStation·Switch Pro 등 브라우저 Gamepad API 표준 배치)로도 조작할 수 있습니다. 연결된 순서대로 첫 번째 컨트롤러가 P1, 두 번째가 P2이며(싱글 플레이에서는 P1만), 터치·키보드와 함께 받습니다. 브라우저는 컨트롤러 버튼을 한 번 눌러야 컨트롤러를 인식합니다. 코드는 [`src/input/gamepad.js`](src/input/gamepad.js)에 있습니다.

| 컨트롤러 | 동작 |
| --- | --- |
| 왼쪽 스틱 · 십자키 ←/→ | 이동 |
| 오른쪽 스틱 | 기울인 방향으로 조준(상대 쪽 반원만). 십자키 ↑/↓는 키보드 W/S처럼 조준선 회전 |
| RT · A(×) | 누르고 있으면 연사(RPG·저격총은 떼면 발사) |
| RB · X(□) | 무기 전환 |
| LB · B(○) | 수류탄 |
| Start | 일시정지 / 계속 |

메인 메뉴·캐릭터 선택·싱글 플레이 설정·일시정지·결과·밸런스 조정 화면도 컨트롤러로 조작합니다(Xbox 컨트롤러 기준, 연결된 어느 컨트롤러로든). 코드는 [`src/input/padmenu.js`](src/input/padmenu.js)에 있습니다.

| 컨트롤러 | 메뉴 화면에서 |
| --- | --- |
| 십자키 · 왼쪽 스틱 | 화면 배치대로 위·아래·왼쪽·오른쪽 버튼으로 이동(누르고 있으면 반복). 처음 누르면 그 화면의 강조 버튼(시작·계속 등)을 고름 |
| A | 선택(고른 버튼 누르기). 숫자 칸에서는 값 고치기 시작 → 십자키 ↑/→ 올림, ↓/← 내림 → A로 끝 |
| B | 취소: 이전 화면으로(일시정지에서는 계속, 결과·준비·밸런스에서는 메인 메뉴 등). 숫자 칸을 고치는 중이면 고치기만 끝 |
| 오른쪽 스틱 ↑/↓ | 화면 스크롤(결과 통계 표 등) |

B를 눌렀을 때 누를 버튼은 화면마다 `index.html`의 `data-pad-cancel` 속성으로 정합니다.

경기 화면에서는 브라우저의 핀치 확대/축소·더블탭 확대·페이지 스크롤을 막습니다(iOS Safari는 `user-scalable=no`를 무시하므로 CSS `touch-action`과 [`src/input/gestures.js`](src/input/gestures.js)에서 터치·제스처 이벤트의 기본 동작을 취소). 메뉴·밸런스 화면의 한 손가락 스크롤은 그대로입니다.

이동·조준·발사 키: P1 `A`/`D` 이동, `W`/`S` 조준, `F` 발사 · P2 `←`/`→` 이동, `↑`/`↓` 조준, `Enter` 발사.

기본 선택은 그림 속 무기와 같습니다: 온이름 쌍권총, 요원 1 권총, 피자럭스 돌격소총, 요원 2 RPG.

**지구방위팀 요원 · 코드네임 X·V·R, 시리우스 K**: 캐릭터 선택 화면에 네 명이 더 있습니다. 그림은 사용자가 준 캐릭터 소개 그림(사용 허락 받음)에서 배경을 지우고, 정해진 무기로 **총을 쏘는 모습**(총구 불꽃·탄피)으로 손질했습니다. 이 캐릭터를 고르면 주무기도 그림 속 무기로 바뀌며, 그 뒤에 다른 무기로 바꿀 수 있습니다. 체력·히트박스·이동 속도는 다른 사람 캐릭터와 같고(500·30·300), 키 큰 전신 그림이라 1.2배로 그립니다.

| 캐릭터 | 그림 속 무기 | 그림 손질 |
| --- | --- | --- |
| 코드네임 X | 돌격소총 | 들고 있던 스케이트보드를 지우고, 그 손으로 돌격소총을 허리 높이에서 쏨 |
| 코드네임 V | 쌍권총 | 브이 하던 손가락을 지우고, 두 주먹의 권총으로 양옆을 쏨 |
| 코드네임 R | 저격총 | 가슴 앞 손으로 저격총을 수평으로 겨눠 쏨 |
| 시리우스 K | 권총 | 위로 들던 권총을 장갑 낀 두 손으로 앞을 겨눠 쏘는 모습으로 바꿈(겹쳐 있던 아이콘을 지우고, 오른쪽을 보게 좌우 반전) |

**주무기**

| 총기 | 발사 방식 | 한 발 피해 |
| --- | --- | --- |
| 돌격소총 | 누르고 있으면 0.2초마다 | 7 |
| 권총 | 누르고 있으면 0.5초마다 | 20 |
| 쌍권총 | 누르고 있으면 0.5초마다 2점사 | 10 |
| RPG | 조준한 뒤 **손을 떼면** 한 발, 발사 후 쿨타임 1초 (탄속 900, 유도) | 직접 명중 40, 폭발 범위(주변 적) 10 |
| 저격총 | 조준한 뒤 **손을 떼면** 한 발, 발사 후 쿨타임 1초 (탄속 1600, 긴 조준선). 고르면 팀 진영에 **강철 엄폐물** | 60 |
| 아킴보 석궁(숨겨진 무기) | 무기 목록에 없고, **쌍권총 버튼을 빠르게 2번** 누르면 그 버튼이 아킴보 석궁으로 바뀜(한 번 누르면 쌍권총으로). 권총 손잡이가 달린 소형 석궁 두 자루. 누르고 있으면 0.7초마다 **화살 2개가 나란히** 날아감(탄속 1500으로 빠름, 화살 간격 26) | 화살 1개 12 |

**보조무기·아이템** (드론 R-10은 쓸 수 없음)

| 무기 | 발사 방식 | 피해 |
| --- | --- | --- |
| 기관단총(보조무기, 기본) | 누르고 있으면 0.1초마다. 4초 연속으로 쏘면 과열되어 2초 동안 쏠 수 없음. 쉬는 동안엔 식음 | 한 발 4 |
| 단검(보조무기) | 조준한 뒤 **손을 떼면** 조준 방향으로 **매우 빠르게 돌진**(초당 2400). 상대 몸에 닿거나 엄폐물·상대 레일에 닿으면 원래 자리로 돌아옴. **돌진하는 동안(돌아올 때까지) 무적**이라 탄·폭발이 통과함. 쿨타임 10초 | 닿으면 100 |
| 샷건(보조무기) | 조준한 뒤 **손을 떼면** 부채꼴(40도)로 총알 5개 발사(탄속 900). 쿨타임 10초 | 총알 1개 40 |

단검·샷건의 쿨타임은 그 무기만 따로 돌며, 쿨타임 중에도 주무기는 바로 쓸 수 있습니다. 쿨타임 동안 조작 패널의 보조무기 버튼에 남은 초가, 캐릭터 아래에 보라색 막대가 표시됩니다. 피해·쿨타임·돌진 속도, 샷건 총알 개수·부채꼴 각도·탄속, 석궁 연사 간격·탄속·화살 간격은 밸런스 조정 메뉴에서 바꿀 수 있습니다.
| 수류탄(아이템) | 아이템 버튼을 누르면 지금 조준 방향으로 던짐. 엄폐물·사람 위로 날아가 적 레일 선에서 폭발. 던진 뒤 쿨타임 20초 | 반경 240(RPG의 2배) 안의 적 모두 50, 엄폐물도 깎음 |

**드론 R-10**: 아래에 카메라, 앞에 레이저 발사기 2개가 달린 드론입니다. 다른 캐릭터보다 크게 그려지고(1.4배) **맞는 판정도 넓습니다**(반지름 48, 사람은 30). **체력은 400**입니다. 주무기는 **레이저 캐논**만 쓰고 보조무기·수류탄은 없습니다. 레이저 캐논은 누르고 있으면 0.7초마다 붉은 **레이저 탄환을 3점사**(0.08초 간격, 탄속 1400)로 쏘고, 한 발에 **20 피해**를 줍니다(엄폐물에 막히며 엄폐물을 깎음). 쏠 때마다 배터리가 닳아 15발(3점사 5번, 약 3초)을 쏘면 방전되고, 마지막으로 쏜 뒤 2초가 지나면 배터리가 가득 찹니다. 캐릭터 아래 막대로 배터리(빨강)·기관단총 열(주황)·수류탄 쿨타임(회색)을 보여 줍니다.

**숨겨진 캐릭터 · 아크 트루퍼**: 캐릭터 선택 화면에서 **온이름 버튼을 빠르게 2번 누르면**(0.5초 안) 그 버튼이 아크 트루퍼로 바뀌고 선택됩니다. 아크 트루퍼가 된 버튼을 한 번 누르면 온이름으로 돌아옵니다. **하얀 갑옷**을 입은 병사에 **얼굴은 온이름**이며, **제트팩으로 떠서 움직이며 움직일 때 제트팩에서 불꽃이 나오고, 다른 캐릭터(초당 300)보다 빠릅니다(초당 420)**. 그림은 직접 그린 하얀 갑옷 몸통에 온이름 머리를 합성한 것입니다(받은 참고 그림은 공식 저작물이라 쓰지 않음). 무기는 다른 캐릭터처럼 자유롭게 고르고, **상대에게 피해를 줄 때마다 5를 더 줍니다**(총알·폭발·돌진 모두, 밸런스 메뉴에서 조절).

**숨겨진 캐릭터 · 제작자**: 온이름 버튼을 **빠르게 3번** 누르면 나타납니다(2번째에 아크 트루퍼로 바뀌었다가 3번째에 제작자로 바뀜). 한 번 누르면 온이름으로 돌아옵니다. 모습은 온이름인데 몸에 빨간 글씨로 '제작자'라고 써 있습니다. 전용 주무기 **즉사기**만 씁니다(보조무기·수류탄 없음).

| 전용 주무기 | 발사 방식 | 피해 |
| --- | --- | --- |
| 즉사기 | 커다란 레이저포. **전투 시작 30초 뒤부터** 쏠 수 있고(그 전엔 버튼에 남은 초, 캐릭터 아래 빨간 막대가 차오름), 쏘면 거대한 레이저가 조준 방향에서 가장 가까운 상대 쪽으로 휘어 들어감. 기본은 **무조건 맞음**(유도 180도, 엄폐물·단검 무적도 무시). 쏜 뒤 **쿨타임 10초**가 지나면 다시 쏠 수 있음(계속 사용 가능) | 즉사(기본 9999) |

밸런스 조정 메뉴에서 즉사기의 **피해**(9999면 즉사, 줄이면 그만큼만), **유도 각도**(조준 방향에서 최대 몇 도까지 휘는지, 180이면 어디를 겨눠도 명중·작게 하면 비슷하게 겨눠야 맞음), **사용 가능 시각**(전투 시작 후 몇 초), **쿨타임**(쏜 뒤 다시 쓸 때까지)을 바꿀 수 있습니다. 경기가 끝나면 마지막 한 방이 보이도록 결과 화면은 약 1초 뒤에 뜹니다.

RPG는 가장 가까운 적 쪽으로 휘어 날아가며(초당 최대 약 46°, 약하게), 빗나가도 적 레일 선·경기장 끝·수명 끝에서 반드시 터져 주변에 폭발 피해를 줍니다.

경기장(1600×1000)에는 **엄폐물 3개**가 있습니다. 가운데 1개와 각 팀 진영 앞에 1개씩(점대칭 배치)이며, 양 팀 총알을 막고 RPG는 엄폐물에 닿으면 그 자리에서 폭발합니다. 엄폐물은 **내구도 200**이며 양 팀 총알(한 발 피해만큼), RPG 직격(2배, 80), RPG 폭발 범위(10)에 깎입니다. 전투기 미사일은 엄폐물 위로 넘어가므로 막히지도 깎지도 않습니다. 깎일수록 금이 가고 위에 내구도 바가 뜨며, 0이 되면 부서져 그 경기 동안 다시 생기지 않습니다. 주무기로 **저격총**을 고른 플레이어가 있으면, 그 팀 진영(팀 엄폐물 반대쪽)에 경기 내내 **강철 엄폐물**이 하나씩 생깁니다. 강철 엄폐물은 부서지지 않고 양 팀 총알·레이저를 모두 막습니다.

가끔 **전투기**가 무작위로 나타나 경기장 가운데 하늘 위를 가로로 지나갑니다. 전투기는 높이 날기 때문에 **총알·RPG·레이저는 전투기 밑으로 그냥 지나갑니다**(막지 않음). 화면 안에 있는 동안 **1초마다 위·아래 양방향으로 미사일**을 쏴서 양 팀 모두를 공격합니다. 미사일은 직격 20에 주변 폭발 피해 8(반경 120)이고, 유도 없이 똑바로 날아가며, 엄폐물을 넘어가 플레이어에게 직접 날아갑니다. 빗나가면 목표 레일 선에서 터집니다. 전투기가 지나가는 동안 위치에 따라 좌우로 움직이는 엔진 소리가 나고, 총을 쏠 때마다 총기별 총성이 납니다. 기본 수치는 [`src/game/config.js`](src/game/config.js)의 `CHARACTERS`·`WEAPONS`·`JET`·`COVER`·`RULES`에 있습니다. 두 번째 손글씨 메모(무기표·체력·자동 발사·옥상·전투기)를 반영한 업그레이드이며, 이전 버전의 "10점 선취" 규칙은 체력제로 바뀌었습니다.

### 싱글 플레이 (vs AI)

메인 메뉴의 **싱글 플레이**에서 혼자 AI와 대결합니다. 플레이어는 P1(지구방위팀) 자리에서 캐릭터 5명 중 누구든 고르고, AI는 P2(ISB팀) 자리에서 **요원 1·요원 2 중 경기마다 무작위**로 정해집니다. 설정 화면에서 AI에 대해 다음을 정할 수 있으며, 설정은 브라우저에 저장됩니다.

| 설정 | 내용 |
| --- | --- |
| 난이도 | 쉬움·보통·어려움. 탄을 알아채는 속도, 피하려는 확률, 이동 속도, 조준 예측, 연사 습관, 수류탄 빈도가 달라짐 |
| AI 주무기·보조무기 | 주무기 5종(+숨겨진 아킴보 석궁), 보조무기(기관단총·단검·샷건) 중 플레이어가 정함 (수류탄은 공통) |
| AI 히트박스 | 몸 판정 반지름 (기본 30, 클수록 잘 맞음) |
| AI 체력 | 기본 500 |
| AI 탄속 | 무기 기본 탄속 대비 % (기본 100%) |
| 주무기·보조무기·수류탄 피해 | AI만 적용. 비워 두거나 기본값이면 무기 기본 피해(RPG는 폭발 피해도 같은 비율로) |

AI는 **언제나 플레이어를 향해 조준**하고(보통·어려움은 플레이어가 움직이는 방향 앞을 예측), 날아오는 플레이어의 탄·RPG·수류탄과 전투기 미사일을 **좌우로 움직여 피합니다**. 엄폐물에 가로막히면 트인 자리로 옮기고, 가끔 기관단총으로 바꿔 쓰며 쿨타임이 끝나면 수류탄을 던집니다. AI 자리의 키보드 키(방향키·Enter 등)는 쓰이지 않습니다. 코드는 [`src/game/ai.js`](src/game/ai.js)에 있습니다.

### 스토리 모드 (싱글 플레이)

싱글 플레이 화면 맨 위에서 **자유 대전**(위의 AI 1:1) 대신 **스토리 모드**를 고르면, 플레이어(P1) 혼자 ISB팀 요원들을 웨이브마다 상대합니다.

**2인 협동**: 스토리 모드를 고르면 나오는 인원 칸에서 **1인 · 2인 협동**을 고릅니다. 2인 협동이면 P2도 **지구방위팀**으로 P1과 같은 아래 레일에서 함께 싸웁니다(P2 캐릭터·무기는 그 아래 P2 칸에서 고르고, 기본은 피자럭스 돌격소총). P2는 2인 대결처럼 **오른쪽 조작 패널**·방향키(`←`/`→`·`↑`/`↓`·`Enter`·오른쪽 `Shift`·`/`)·두 번째 컨트롤러로 조작합니다. 요원 수·체력은 1인과 같고, 요원과 복도 포탑은 **가까운 주인공**을 노립니다. 한 명이 쓰러져도 다른 한 명이 서 있으면 계속하고, **둘 다 쓰러지면 패배**입니다. 쓰러진 동료는 **스테이지를 깰 때(옥상 → 복도) 체력 가득으로 다시 일어납니다**. 킬캠·엔딩 컷씬의 주인공은 그 요원·보스를 쓰러뜨린 쪽입니다. 저장하기는 두 사람의 체력·선택을 함께 저장하고(쓰러진 쪽은 체력 0, 이어 하면 쓰러진 채로), 이어하기는 저장할 때의 인원으로 이어 합니다. 스테이지는 **1스테이지 옥상**과 **2스테이지 복도** 두 개입니다. 체력은 웨이브 사이에는 회복되지 않고, **스테이지를 깰 때마다 100% 회복**됩니다. 웨이브를 깨면 쓰러진 요원은 치워지고 다음 웨이브가 옵니다.

**AI 동료**: 스토리 모드 인원 칸 아래에서 **AI 동료 없음·1명·2명·3명**을 고르면 지구방위팀 AI가 함께 싸웁니다(1인·2인 협동 모두). 동료마다 **캐릭터와 주무기를 직접 고릅니다**(동료 수를 고르면 그 아래에 동료 칸이 나옴, 캐릭터를 고르면 주무기는 그 캐릭터의 그림 속 무기로 바뀌고 다시 바꿀 수 있음, R-10은 레이저 캐논 고정). 동료는 AI(난이도 보통)이고 **주무기만 씁니다**(보조무기·수류탄 없음). 고른 동료는 브라우저에 저장됩니다. 그 대신 **동료 수만큼 일반 웨이브마다 쉬움 난이도의 돌격소총 요원이 더 나옵니다**(체력 등은 그 웨이브 설정과 같음, 스미스 요원·R-10 보스전에는 추가 없음). 동료가 쓰러져도 계속하고, 쓰러진 동료는 스테이지를 깰 때 일어납니다. **사람 주인공이 모두 쓰러지면 동료가 남아 있어도 패배**입니다. 동료가 요원을 쓰러뜨려도 건 카타는 사람 주인공이 하고, 저장하면 동료 수도 함께 저장됩니다.

**저장하기 · 이어하기**: 스토리 모드 중 일시정지 화면의 **저장하기**를 누르면 지금 싸우는 웨이브(웨이브 사이라면 다음에 올 웨이브)와 체력, 고른 캐릭터·무기를 브라우저에 저장합니다. 메인 메뉴로 나가거나 창을 닫았다가 다시 들어와도 메인 메뉴(또는 싱글 플레이 화면의 스토리 칸)의 **스토리 이어하기**로 그 웨이브의 요원이 오는 장면부터 저장한 체력으로 이어 합니다(쓰러뜨리던 요원은 처음부터). 스미스 요원 엔딩 컷씬 중에 저장하면 복도 1웨이브·체력 가득으로 저장됩니다. 이어 하거나 저장한 판에서 **재대결·다시 시작**을 누르면 그 저장 위치부터 다시 하고, 스토리를 끝까지 깨면 저장은 지워집니다. 싱글 플레이 화면의 **저장 지우기**로 지울 수도 있습니다.

**음악·경고음**: 경기가 시작되면(카운트다운부터) 신나는 **배틀 음악**이 나옵니다(파일 없이 Web Audio로 합성, 모든 모드). 스토리 모드에서 요원이나 보스가 등장할 때마다(1웨이브 시작, 헬리콥터 접근, 건쉽 접근, 엘리베이터 도착, 천장 붕괴) **경고 사이렌**이 울리고 그동안 음악 소리가 작아졌다가 돌아옵니다. 일시정지·결과·메뉴에서는 음악이 멈추고, 음소거를 켜면 음악도 꺼집니다. 코드는 [`src/audio/music.js`](src/audio/music.js).

**처치 컷씬(킬캠)**: 스토리 모드에서 요원을 쓰러뜨릴 때마다 경기가 잠깐(약 1.4초) 멈추고, 카메라가 쓰러진 요원을 확대하며 'K.O.!'와 요원의 마지막 한마디(무작위)가 자막으로 나옵니다. 웨이브의 마지막 요원이면 웨이브마다 다른 장면이 이어집니다.

R-10이 내려앉으면 카메라가 R-10을 확대하고 자막으로 **"넌 나를 이길 수 없음! 도발하기!"**가 나옵니다. 킬캠·도발 장면 동안은 탄·전투기·포탑·AI가 모두 멈추고 조작할 수 없습니다. 스미스 요원과 R-10은 킬캠 대신 아래 엔딩 컷씬이 나옵니다.

**조작 패널(스토리 1인)**: 스토리 모드를 혼자 할 때는 조작 패널 하나가 화면 너비를 다 씁니다. **이동키는 왼쪽 끝, 발사키는 오른쪽 끝**에 있고, 주무기·보조무기·수류탄(아이템) 버튼은 **발사키 바로 옆**에 있습니다. 가운데에는 이름과 일시정지 버튼이 있습니다. 2인 협동은 2인 대결처럼 P1 왼쪽·P2 오른쪽 패널입니다.

**건 카타 모드(모든 요원·스미스 요원·R-10)**: 스토리 모드에서 **요원을 쓰러뜨릴 때마다**(스미스 요원과 R-10 포함) **건 카타 모드**에 들어갑니다. 화면이 **옆에서 본 시점**(옥상은 밤의 옥상 끝과 도시 불빛, 복도는 본부 복도)으로 바뀌어 주인공(왼쪽)과 쓰러뜨린 적(오른쪽)이 마주 보고 서고, 조작 패널은 모두 사라지고 **가운데에 1·2·3·4 버튼**만 남습니다. 적이 아래 네 가지 공격을 무작위로 하는데, **공격하기 0.5초 전부터 눌러야 할 버튼이 0.5초 동안 빛납니다**(화면 가운데에도 번호와 줄어드는 시간 고리). 빛나는 동안 그 버튼을 누르면 대응(반격) 성공, **0.5초 안에 못 누르거나 다른 버튼을 누르면 체력 100이 깎입니다**. **일반 요원은 3번, 보스(스미스 요원·R-10)는 10번 대응하면** 건 카타가 끝나고 원래 장면이 이어집니다: 일반 요원은 처치 컷씬(킬캠: 마지막 한마디·웨이브 마무리 장면), 스미스 요원은 아래 엔딩 컷씬, R-10은 RPG 엔딩 컷씬. 2인 협동이면 그 적을 쓰러뜨린 주인공이 합니다. 체력이 0이 되면 패배입니다(2인 협동이면 살아 있는 동료가 이어받음). 건 카타 중에는 저장할 수 없고, 일시정지하면 그 자리로 돌아옵니다. 코드는 [`src/game/gunkata.js`](src/game/gunkata.js)(진행)·[`src/input/kata.js`](src/input/kata.js)(버튼)이고, 그림은 `src/render/canvas.js`의 건 카타 부분입니다.

**R-10 엔딩 컷씬**: R-10을 쓰러뜨리면 결과 화면 전에 약 9초 컷씬이 나옵니다. R-10이 다시 떠올라 **레이저 광선을 마구 쏘지만 주인공이 좌우로 피하고**(모두 빗나감), 주인공이 "후, RPG가 남아있었지." → R-10 "그게 무슨-" → 주인공이 **RPG를 쏴 R-10을 폭발**시킵니다. 이어서 아래 라이트닝 컷씬 뒤 3스테이지 하늘이 시작됩니다. 컷씬 동안은 조작할 수 없고, 일시정지하면 컷씬 그 자리로 돌아옵니다.

**라이트닝 컷씬(복도 → 하늘)**: 약 10초. 화면이 어두워졌다가 **옥상으로 올라온 주인공**이 무전으로 "본부! 여기는 옥상. **내 전용기 라이트닝을 보내 줘!**" → 본부 "라이트닝 출격! 행운을 빈다." → 라이트닝(쌍동 프로펠러 전투기)이 날아와 주인공 위에 멈추고, 주인공이 올라타 날아오르면 화면이 하얘지며 3스테이지 하늘로 바뀝니다(체력 100% 회복). 이 컷씬 중에 저장하면 하늘 1웨이브로 저장됩니다.

### 밸런스 조정 (알파)

메인 메뉴의 **밸런스 조정**에서 캐릭터별 체력·히트 박스 반지름·이동 속도, 무기별 피해·발사 간격(쿨타임)·탄속·점사·폭발 피해/반경·유도·배터리·과열, 수류탄, 엄폐물 내구도, 전투기 등장·미사일, 무기 전환 대기·탄환 수명을 바꿀 수 있습니다. 바꾼 값은 그 브라우저에 저장되어 다음 경기부터 적용되고, **모두 기본값으로**로 되돌립니다.

**현재 수치 보기**는 전체 수치를 한 화면에 모아 보여 줍니다. 기본값과 다른 칸은 노랗게, 괄호 안에 기본값을 표시하므로 그대로 캡처해 전달하면 됩니다. **텍스트로 복사**하면 같은 내용과 변경값 JSON이 복사됩니다. 전달받은 값을 새 기본값으로 삼으려면 `src/game/config.js`의 해당 수치를 고칩니다. 조정 가능한 항목 목록은 [`src/game/balance.js`](src/game/balance.js)에 있습니다.

### 무기별 캐릭터 그림

지금 캐릭터 그림은 캐릭터마다 한 장이며 기본 주무기가 그려져 있어(온이름 쌍권총, 요원 1 권총, 피자럭스 돌격소총, 요원 2 RPG, R-10 레이저 발사기), 무기를 바꿔도 모습은 그대로입니다. 온이름·요원 1 그림은 원래 그림을 편집해 만들었습니다(온이름 머리 + 요원 1의 쌍권총 든 몸, 넥타이는 파랑 / 요원 1은 들어 올린 권총을 지움). R-10은 직접 그린 SVG입니다. 무기별 그림을 넣으면 든 무기에 따라 모습이 바뀝니다.

1. `assets/characters/<캐릭터 id>@<무기 id>.png` 로 저장합니다. 예: `earth-arrow@sniper.png`
   - 캐릭터 id: `earth-arrow`, `earth-pizza`, `isb-agent-1`, `isb-agent-2`
   - 무기 id: `rifle`, `pistol`, `dual`, `rpg`, `sniper`, `smg`, `grenade`
   - 기존 그림처럼 정사각형·투명 배경·오른쪽을 보는 자세로 맞추면 됩니다.
2. `assets/manifest.json`의 `assets`에 항목을 추가합니다. `id`는 파일 이름과 같은 `<캐릭터 id>@<무기 id>`, `bodyAnchor`는 몸 중심 위치(0~1 비율)입니다. 기존 캐릭터 항목을 복사해 `id`·`path`만 바꾸면 됩니다.

그림이 없는 조합은 기본 그림을 그대로 씁니다. `assets` 폴더는 통째로 배포되므로 워크플로 수정은 필요 없습니다.

캐릭터 이미지는 정적 완성 포즈입니다. 움직이는 팔·총의 분리 파츠나 프레임 애니메이션 시트는 포함하지 않으며, MVP에서는 별도 조준선과 간단한 전체 스프라이트 변형으로 동작을 표현합니다.

## 배포 (GitHub Pages)

주소: https://umid-podo.github.io/hahaha-shoot-001/

`main`에 push하면 [`.github/workflows/deploy-pages.yml`](.github/workflows/deploy-pages.yml)이 게임 실행에 필요한 파일만 모아 배포한다. 문서와 테스트는 사이트에 올라가지 않는다. 게임이 새 파일이나 폴더를 쓰게 되면 워크플로의 `Collect game files` 단계에도 추가한다. 빠뜨리면 사이트에서 404가 난다.

### Claude Code Cloud에서 배포

"배포해줘"라는 요청을 받으면 아래 순서대로 진행한다. 클라우드 세션은 자기 작업 브랜치에만 push할 수 있으므로 PR로 `main`에 반영한다.

1. 테스트: `npm test`.
2. 변경 사항을 커밋하고 작업 브랜치를 push한다.
   ```sh
   git push -u origin HEAD
   ```
3. PR을 만들고 병합한다. 병합되면 `main` push로 배포가 자동으로 시작된다. 이미 열린 PR이 있으면 새로 만들지 않고 그 PR을 병합한다.
   ```sh
   gh pr create --repo umid-podo/hahaha-shoot-001 --base main --fill
   gh pr merge --repo umid-podo/hahaha-shoot-001 --merge
   ```
4. 병합이 막히면 작업 브랜치를 바로 배포한다. `github-pages` 환경은 `main`과 `claude/*` 브랜치의 배포만 허용한다.
   ```sh
   gh workflow run deploy-pages.yml --repo umid-podo/hahaha-shoot-001 --ref "$(git branch --show-current)"
   ```
   이 경우 `main`에는 아직 반영되지 않았으므로 사용자에게 PR 병합을 요청한다. 병합하지 않으면 다음 `main` 배포가 이 변경을 덮어쓴다.
5. 배포 실행이 끝날 때까지 기다린다. 실행 목록에 바로 보이지 않으면 몇 초 뒤 다시 조회한다.
   ```sh
   gh run list --repo umid-podo/hahaha-shoot-001 --workflow deploy-pages.yml --limit 1
   gh run watch <실행 ID> --repo umid-podo/hahaha-shoot-001 --exit-status
   ```
6. 사이트가 `200`을 돌려주는지 확인하고 주소를 사용자에게 알린다. 클라우드 네트워크에서 `github.io`에 접속할 수 없으면 5번의 성공 결과로 대신하고, 그렇게 보고한다.
   ```sh
   curl -s -o /dev/null -w '%{http_code}\n' https://umid-podo.github.io/hahaha-shoot-001/
   ```

### 로컬에서 배포

`main`에서 커밋하고 `git push`하면 된다. 확인은 위 5~6번과 같다.

### 처음 설정 (완료됨)

저장소 Settings → Pages의 Source는 **GitHub Actions**이고, Settings → Environments → `github-pages`의 배포 브랜치는 `main`, `claude/*`로 제한되어 있다. Pages 설정이 꺼졌다면 아래 명령으로 다시 켠다.

```sh
gh api -X POST repos/umid-podo/hahaha-shoot-001/pages -f build_type=workflow
```

배포 브랜치 제한이 사라졌다면 아래 명령으로 되살린다. 마지막 줄이 `claude/*,main`을 출력하면 된다.

```sh
echo '{"deployment_branch_policy":{"protected_branches":false,"custom_branch_policies":true}}' | gh api -X PUT repos/umid-podo/hahaha-shoot-001/environments/github-pages --input -
gh api -X POST repos/umid-podo/hahaha-shoot-001/environments/github-pages/deployment-branch-policies -f name=main -f type=branch
gh api -X POST repos/umid-podo/hahaha-shoot-001/environments/github-pages/deployment-branch-policies -f name='claude/*' -f type=branch
gh api repos/umid-podo/hahaha-shoot-001/environments/github-pages/deployment-branch-policies --jq '[.branch_policies[].name]|join(",")'
```
