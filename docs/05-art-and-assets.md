# 아트 가이드·에셋 명세

## 원본 유지

원본 캐릭터의 큰 머리, 검은 정장, 선글라스, 웃거나 자신감 있는 표정과 무기를 유지한다. 온이름은 파란 화살표·파란 넥타이, 피자럭스는 피자 모자·노란 얼굴·노란 넥타이, 요원 1은 뾰족한 머리·쌍권총, 요원 2는 옆머리·붉은 발사관·녹색 RPG 탄두가 핵심이다.

**[제안]** 굵은 외곽선과 단순한 명암의 2D 캐릭터로 정리했다. 종이 메모 느낌의 배경은 중앙을 비워 탄환을 읽기 쉽게 한다. 원본에 없는 스토리·실존 브랜드 표식은 추가하지 않는다.

## 게임 적용

- 캐릭터 PNG는 알파가 있는 정적 포즈 1장씩. 스프라이트 시트·걷기 프레임·무기 분리 파츠가 아니다.
- 머리 화살표와 총 길이 차이로 이미지의 중앙이 몸 중앙과 다르다. manifest의 정규화된 몸 앵커를 물리 좌표에 맞추고 원형 충돌 반지름은 모든 캐릭터에 동일하게 적용한다.
- 표시 범위는 최대 128×128이며 종횡비를 유지한다. 원본 100%와 게임 표시 크기에서 식별성을 확인한다.
- 시선 반전은 Canvas X 스케일 반전으로 가능하나 앵커도 반전한다. 상단 팀 이미지를 거꾸로 뒤집지 않는다.
- 총·팔을 독립 회전하려면 추가 에셋이 필요하다. 현재는 전체 포즈를 고정하고 조준선을 별도 렌더링한다.
- 배경의 레일은 장식이다. 런타임에서 정확한 y=92/692에 얇은 기준선을 덧그려 판정 위치를 보장한다. 중앙에 장애물 충돌을 만들지 않는다.
- 팀 링/조준선은 지구방위팀 파랑 `#247BDB`, ISB팀 주황 `#D56A26`을 제안한다. P번호와 문양도 함께 표시한다.
- 스틱 SVG는 기본 판만 제공한다. 드래그 손잡이·쿨다운·키 안내는 DOM/Canvas가 별도로 그린다.
- 탄환 SVG는 오른쪽을 향하므로 실제 조준 각도로 회전한다. 시각 크기와 충돌 원을 구별해 튜닝한다.

## 애니메이션·사운드 후속 작업

MVP에는 이동 시 ±2px 바운스, 발사 시 80ms 축소 반동, 피격 150ms 별 효과를 코드로 구현할 수 있다. 동작 줄이기 설정에서는 정적 표시한다. 이후 필요 시 idle 2프레임, 이동 4프레임, 발사 2프레임과 독립 무기 파츠를 제작한다.

효과음 파일은 이번 패키지에 포함하지 않는다. 발사·적중·승리의 짧은 Web Audio 합성음을 구현 단계에서 작성하고 음량 제한·음소거를 적용한다.

## 출처·검수

원본은 사용자가 제공한 메모 두 장이다. 생성 프롬프트와 사용 도구는 [생성 이력](07-generation-log.md)에 기록한다. 별도의 외부 스톡 이미지는 사용하지 않았다. 법적 권리 상태나 독점성을 이 문서가 보증하지 않는다.
