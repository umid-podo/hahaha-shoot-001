# 게임 기획서

## 개요

**[원문]** 지구방위팀과 ISB팀이 두 개의 수평 레일에서 싸우는 2D 대전 슈팅 게임. 이동과 조준을 동시에 조작하고 적중 횟수로 승부한다.

**[제안]** 짧은 라운드와 알아보기 쉬운 큰 캐릭터를 중심으로 한 캐주얼 웹 게임. 다운로드·로그인 없이 공유 화면에서 시작한다. **2인 전용**(한 화면에서 P1 대 P2)으로 결정했으며, 원문의 4인 구성(R07)은 제외한다. 첫 버전은 로컬 2인, 조작법 안내, 결과 화면(통계), 밸런스 조정, 음소거와 재대결까지 제공한다. 온라인 대전·AI·계정·랭킹·상점은 후속 범위다.

## 플레이 흐름

시작 → 대결 시작 → P1·P2 캐릭터·주무기 선택 → 3초 카운트다운 → 이동·조준·발사·무기 선택·수류탄 → 적중 시 상대 체력 감소 → 한쪽 체력 0 판정 → 결과(무기별 통계) → 재대결, 캐릭터 선택 또는 메인 메뉴.

(원문의 10점 선취 규칙은 두 번째 메모에 따라 체력제로 바뀌었다. 아래 경기 규칙·밸런스 표의 점수·무적 항목은 첫 버전 기록이며, 현재 규칙은 README와 `src/game/config.js`가 기준이다.)

## 팀과 캐릭터

| 슬롯 | 팀/위치 | 기본 캐릭터 | 무기 외형 |
| --- | --- | --- | --- |
| P1 | 지구방위팀/하단 | 온이름 | 돌격소총(현재 그림은 쌍권총) |
| P2 | ISB팀/상단 | 요원 1 | 쌍권총(현재 그림은 권총) |

**[원문]** 2인 구성은 위와 같다. **[결정]** 2인 전용이므로 P3·P4 슬롯은 없다. 4인용이던 피자럭스·요원 2와 드론 R-10은 준비 화면에서 P1·P2가 골라 쓸 수 있는 캐릭터로 남긴다. 캐릭터별 체력·히트 박스·이동 속도는 밸런스 조정 메뉴에서 바꿀 수 있다. ISB의 약어나 배경 이야기는 원문에 없으므로 추가 정의하지 않는다.

## 경기 규칙

1. **[원문]** 캐릭터는 자기 레일의 X축으로만 이동한다.
2. **[원문]** 조준 스틱 드래그로 180도 조준하고 놓을 때 총알을 발사한다.
3. **[원문]** 상대 명중은 공격자 팀에 1점, 아군 공격은 불가능하다.
4. **[원문]** 10점을 먼저 얻은 팀이 우승한다.
5. **[제안]** 탄환 하나는 상대 한 명에게 한 번만 적중하고 제거된다. 아군은 통과한다.
6. **[제안]** 피격자는 사망·탈락·위치 초기화 없이 0.6초 무적이 된다. 무적 적에 닿은 탄환은 점수 없이 제거한다.
7. **[제안]** 같은 틱의 피격 이벤트를 모두 모은 뒤 승패를 판정한다. 양 팀 동시 10점은 무승부, 한 팀이 여러 번 맞혀도 화면 점수는 최대 10점이다.
8. **[결정]** 팀마다 한 명뿐이라 아군 판정은 실제로 쓰이지 않는다. 두 플레이어는 P번호·팀 색 링으로 식별한다.
9. **[제안]** 라운드 제한 시간은 없다. 일시정지 중 입력·탄환·무적 타이머가 멈춘다.

## 초기 밸런스 설정 [제안]

단위는 1600×1000 논리 경기장 기준이며 UI 컨트롤 패널은 경기장 외부에 둔다. (최신 수치는 `src/game/config.js`가 기준: 체력 500, RPG 피해 40·탄속 1800, 엄폐물 3개, 전투기 속도 160·1초마다 양방향 20 피해 사격)

| 설정 | 값 | 의도 |
| --- | --- | --- |
| 상단/하단 레일 Y | 92 / 892 | 배경 `rooftop.svg`의 레일 통로와 정렬 |
| 이동 X 범위 | 80–1520 | 화면 밖 이탈 방지 |
| 시작 X | 양 팀 800 | 대칭 시작(2인 전용) |
| 최대 이동 속도 | 300 논리 px/s | 회피 가능 |
| 캐릭터 충돌 반지름 | 30 논리 px | 장식·총은 충돌 제외 |
| 표시 크기 | 최대 128×128 안에 맞춤 | 원본 비율 유지 |
| 탄속 | 720 논리 px/s | 정면 이동 시간 약 0.83초 |
| 탄환 충돌 반지름 | 5 논리 px | 인지성과 판정 일치 |
| 재발사 대기 | 0.35초 | 놓기 이벤트마다 최대 한 발 |
| 탄환 수명 | 2초 | 수평 발사 탄환 정리 |
| 피격 무적 | 0.6초 | 연속 득점 과속 방지 |
| 조준 스틱 데드존 | 반경의 15% | 의도하지 않은 발사 방지 |
| 목표 점수 | 10 | 원문 고정 |

정장과 화살표의 그림 영역은 히트박스와 다르다. 게임 화면에는 몸 중심에 옅은 원형 팀 링을 표시해 판정 위치를 알려준다.

## 무기 처리 [제안]

돌격소총·기관총·쌍권총·RPG라는 원본 무기 구분은 유지한다. 첫 버전에서는 모두 ‘유효한 드래그를 놓으면 투사체 한 개, 적중 1점’이며 자동 연사·쌍권총 2발·RPG 범위 피해는 없다. 녹색 로켓은 시각적 변형으로만 사용할 수 있다. 후속 무기 차별화는 탄속·쿨다운·실제 적중률을 비교한 뒤 별도 설계한다.

## 연출 [제안]

발사 시 짧은 반동, 명중 시 작은 별 모양과 +1, 무적 중 캐릭터 외곽선 표시, 승리 시 팀명과 최종 점수. 피·사망 연출은 사용하지 않는다. 화면 흔들림은 기본 비활성, 동작 줄이기 설정에서 반동과 점수 튀기기도 생략한다.
