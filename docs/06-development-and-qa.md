# 개발 계획과 검수 기준

현재 완료된 것은 메모 분석·문서·정적 그래픽 에셋이다. 아래는 **게임 구현을 위한 제안 일정**이며 구현 완료 보고가 아니다. 기간은 개발자 1인 기준 추정이고 실제 기기 검수 결과에 따라 조정한다.

## 작업 순서

| 단계 | 예상 | 구현물 | 완료 기준 |
| --- | --- | --- | --- |
| 1. 규칙 프로토타입 | 1–2일 | 고정 틱, 레일 이동, 단발, 충돌, 점수 | 원형 임시 표시로도 R01–R07 검증 |
| 2. 입력·2인 | 1–2일 | 이동/조준 동시 터치, 키보드, 취소 처리 | 놓을 때 한 발, 취소 때 0발 |
| 3. 화면 | 1–2일 | 준비·HUD·결과·일시정지 | R08–R13 (2인 전용) |
| 4. 에셋·연출 | 1일 | PNG/SVG 적용, 앵커, 음소거 | 네 캐릭터 식별, 판정과 시각 정렬 |
| 5. 기기 검수 | 1–2일 | 조작 튜닝·성능·오류 처리 | 아래 수용 테스트 통과 |

4인 모드는 범위에서 제외했다(2인 전용). 온라인, 무기별 별도 능력, 프레임 애니메이션은 위 일정에 포함하지 않는다.

## 실제 기기에서 확인

- 데스크톱 브라우저 2종 이상: 키보드 동시 조작·키 재배정·포커스 복귀.
- 태블릿 브라우저(iPad Safari 포함): 2인 4접점 이상(스틱+버튼), 손가락이 다른 패널로 넘어가도 소유권 유지, 핀치·더블탭 확대와 페이지 밀림이 생기지 않음.
- 스마트폰 가로/세로: 메뉴가 잘리지 않고 최소 조작 크기 미달 안내가 동작.
- 2인 5분 연속 경기: 목표 60fps, 프레임 타임과 메모리 추세 기록. 실패하면 DPR·효과·이미지 크기를 조정.
- 이미지 하나 로드 실패, 로컬 저장 금지: 다시 시도/기본 설정으로 진행 가능.
- 음소거·동작 줄이기·키보드 메뉴 탐색: 소리 없이 결과를 읽고 재대결 가능.
- 밝은/어두운 화면 환경: 조준선·탄환·팀 식별 가능. 몸 앵커와 링을 디버그로 표시해 확인.

## 릴리스 완료 조건

R01–R13 연결 테스트를 모두 통과하고 원본 캐릭터 네 명을 올바르게 표시한다. 2인 경기를 시작→종료→재대결까지 완주한다. 문서의 제안값과 실제 설정이 일치해야 한다. 테스트 날짜, 기기, 브라우저 버전, 실패 항목과 수정 사항을 별도 실행 기록에 남긴다. 현재 문서에는 수행하지 않은 런타임 테스트를 통과로 표시하지 않는다.
