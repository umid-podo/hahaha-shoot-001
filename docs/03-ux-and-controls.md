# 화면·입력·사용자 흐름

이 문서의 UI 배치와 세부 입력 규약은 원문 규칙을 구현하기 위한 **제안**이다.

## 화면 구성

| 화면 | 표시 내용 | 행동 |
| --- | --- | --- |
| 시작 | 가칭 제목, 알파 표시, 대결 시작, 밸런스 조정, 조작법, 소리 설정 | 대결 시작 |
| 준비 | P1·P2의 팀·캐릭터·주무기 선택, 키보드 안내 | 시작 |
| 경기 | 상단 ISB 점수, 두 레일, 하단 지구방위 점수, 조준선, 조작 패널, 일시정지 | 플레이 |
| 일시정지 | 계속, 다시 시작, 캐릭터 선택, 메인 메뉴, 음소거 | 계속 또는 라운드 종료 |
| 결과 | 승자 또는 무승부, 경기 시간, 플레이어별 체력·피해·명중률, 무기별 통계 | 재대결, 캐릭터 선택, 메인 메뉴 |
| 밸런스 조정 | 캐릭터·무기·엄폐물·전투기 수치 입력, 기본값 표시 | 수치 변경, 기본값 되돌리기 |
| 현재 수치 보기 | 전체 수치를 한 화면에 모은 요약(변경값 강조) | 캡처, 텍스트 복사 |

점수는 원본처럼 팀별로 경기장 오른쪽에 배치하되 캐릭터 레일과 겹치지 않는 별도 여백에 둔다. 경기장은 3:2 비율로 유지하고 남는 영역은 레터박스로 처리한다.

## 공유 화면 배치

- **2인 전용**: 경기장 아래 왼쪽에 P1, 오른쪽에 P2 패널을 두고, 두 패널 사이 가운데에 일시정지 버튼을 둔다. 두 사람의 손이 부딪히지 않게 P1·P2 패널 사이를 넓게 띄운다.
- 각 패널은 `이동 스틱 | 무기·아이템 버튼 | 조준/발사 스틱` 순서다. 패널이 화면 절반 가까이를 차지하고 두 스틱을 패널 양 끝에 둬서 이동키와 발사키 사이를 최대한 벌린다.
- 스틱 사이의 빈 공간에는 주무기·보조무기 바로 선택 버튼과 아이템(수류탄 던지기) 버튼을 둔다. 버튼 칸이 좁은 화면에서는 세로 한 줄로 쌓는다.
- 모든 플레이어는 화면을 같은 방향으로 본다. 기기를 마주 보고 상단 UI를 뒤집는 방식은 첫 버전에 포함하지 않는다.
- 스마트폰 세로 화면은 메뉴와 조작 설명을 제공하되 2인 플레이에는 가로 화면/태블릿 등 더 큰 화면을 안내한다.
- 패널 한 개의 권장 최소 폭은 380 CSS px, 스틱 터치 영역은 각각 88×88 CSS px, 버튼은 최소 44×44 CSS px. 이 크기를 확보하지 못하면 시작 전 입력 방식 변경을 안내한다.

## 터치·포인터 입력

**이동:** pointerdown 시 해당 플레이어의 이동 스틱이 pointerId를 소유한다. X 변위를 반경으로 나눈 값을 -1…1로 제한한다. 데드존 15% 안은 속도 0, 바깥은 최대 300px/s까지 선형 보간한다. Y 변위는 무시한다. 손을 놓으면 속도 0, 스틱은 중앙 복귀한다.

**조준:** 다른 pointerId를 발사 스틱에 배정한다. 스틱 중심 대비 드래그 벡터로 방향을 정한다. 하단 팀은 위쪽 반원, 상단 팀은 아래쪽 반원으로 제한한다. 드래그가 데드존 밖에 도달하면 발사 준비 상태가 된다. 놓는 순간의 벡터가 데드존 안이면 취소한다. 반대쪽으로 끌면 Y 성분을 0으로 제한하고 X 방향을 사용하며, 벡터 길이도 0이면 이전 방향을 유지한다.

**발사:** 유효한 pointerup에서만 한 번 발생한다. cooldown 중 놓은 입력은 버리고 예약 발사하지 않는다. pointercancel, lostpointercapture, 창 포커스 상실에서는 취소하며 발사하지 않는다. 조준선은 발사 준비 중에만 보인다.

스틱에는 `setPointerCapture`를 사용한다. 패널 밖으로 손이 나가도 자기 스틱을 제어하며 다른 플레이어 패널을 빼앗지 않는다. 경기 화면 전체에 `touch-action: none`을 적용하고, `user-scalable=no`를 무시하는 iOS Safari를 위해 핀치·더블탭 확대와 페이지 스크롤의 기본 동작을 JS로 취소한다(`src/input/gestures.js`). 2인 동시 이동·조준은 최대 4접점, 버튼을 함께 누르면 그 이상이 필요하다. 실제 기기의 다중 터치 지원과 손 가림을 검수한다.

## 키보드 보조 조작

| 플레이어 | 이동 | 조준 각도 회전 | 발사 | 주무기↔보조무기 | 수류탄 |
| --- | --- | --- | --- | --- | --- |
| P1 | A / D | W / S | F | E | Q |
| P2 | ← / → | ↑ / ↓ | Enter | 오른쪽 Shift | / |

조준 회전 속도는 120도/s. 발사키를 누르면 현재 각도로 준비하고 놓으면 한 발 발사한다. 키 반복은 발사를 추가하지 않는다. 키 고스팅이 생기면 터치 조작을 함께 쓴다. 슬롯 하나는 하나의 입력 방식만 소유한다. Escape는 일시정지, 메뉴는 Tab·Enter로 조작한다. 마우스 한 개로 여러 슬롯을 동시에 조작하는 방식은 제공하지 않는다.

## 피드백·접근성

팀 색 외에 팀명·P번호·지구 원형/ISB 방패 문양을 함께 쓴다. 사운드 없이 점수·피격·종료를 인지할 수 있어야 한다. 소리는 첫 사용자 입력 이후 켜고 음소거를 기억한다. 결과와 일시정지는 DOM 텍스트와 버튼으로 제공한다. 동작 줄이기를 지원하고 빠른 전체 화면 점멸은 사용하지 않는다.

## 상태 전환 예외

탭 숨김·포커스 상실 → 모든 입력 취소 → 일시정지. 재개 시 3초 카운트다운 후 진행하며 눌린 키 상태를 이어받지 않는다. 창 크기 변경 시 논리 좌표·점수는 보존하고 CSS 좌표 변환만 갱신한다. 재대결은 점수·탄환·입력·타이머를 초기화하고 같은 인원/캐릭터 배정을 유지한다.
